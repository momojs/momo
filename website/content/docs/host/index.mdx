`@momots/host` provides **host-environment** capabilities for browsers and JS runtimes, with side-effect-free modules, subpath imports, and SSR-safe loading. Features include environment detection, typed storage, binary codecs, CSS color parsing, Canvas text measurement, and browser fingerprints.

## Installation

```bash
bun add @momots/host @momots/core remeda type-fest
```

`@momots/core`, `remeda`, and `type-fest` are peer dependencies and must be installed together.

## Two import styles

Import any function from the root or use subpaths for optimal tree shaking:

```ts
// Import from the root
import { isMobile, measureText, projection, Storagefy } from "@momots/host";

// Import by subpath (bundle only the capabilities you use)
import { isMobile } from "@momots/host/guard/is-mobile";
import { measureText } from "@momots/host/canvas";
import { toCurl } from "@momots/host/fetch";
import { Storagefy } from "@momots/host/storage";
import { projection } from "@momots/host/fingerprint";
```

## Runtime compatibility

Compatibility is assessed per module along two independent dimensions:

- **Import safety**: loading a module does not require browser globals.
- **Behavior level**: calling an API provides **full**, **degraded**, **unavailable**, or **host-specific** behavior in the runtime.

All public entries are safe to import in browsers and Bun, but importability does not imply DOM availability in Bun. Prefer subpath imports in Bun services to keep runtime dependencies explicit.

| Module | Browser | Bun service | Behavior in Bun |
| --- | --- | --- | --- |
| `buffer` | Full | Full | Uses Web Platform `Blob`, Base64, and typed arrays |
| `fetch` | Full | Full | Uses Bun's native Fetch API |
| `storage` | Full | Degraded | Defaults to process-local `MemoryStorage`, without `StorageEvent` |
| `persistent` | Full | Degraded | Default persistence is process-local, not shared across processes or restarts |
| `css/to-rgb` | Full | Full | Pure string parsing, no DOM dependency |
| `css/to-css-variable` | Full | Unavailable | Returns `initial` or `undefined` without a DOM |
| `canvas` | Full | Unavailable | `measureText` returns `undefined` without Canvas |
| `truncated` | Full | Degraded | Returns original text without Canvas |
| `fingerprint` | Browser semantics | Host semantics | Identifies the Bun host/process, not the requesting visitor |
| Web API guards | Full | Full | Recognizes `Blob`, streams, `FormData`, buffers, and similar objects |
| DOM guards and `nearest` | Full | Unavailable | Returns `false` or `undefined` without a DOM |
| UA guards | Full | Full with explicit input | Pass the request UA; the default describes the Bun service itself |

Bun services can directly use `buffer`, `fetch`, `css/to-rgb`, and Web API guards. Storage requires accepting process-local fallback or injecting external `Storage`; DOM, Canvas, and visitor fingerprints belong in the browser.

## Capability map

| Topic | Subpath | Representative APIs |
| ----------- | ------------- | ---------------------------------------------- |
| Guards | `guard/is-*` | `isMobile`, `isElement`, `isCSSStyleRule`, `isBlob`, `isSSR` … |
| Storage | `storage` | `Storagefy`, `StoragefyAsync`, `MemoryStorage` |
| Buffers | `persistent` | `PersistentBuffer` |
| Binary data | `buffer` | `bytesToHex`, `hexToBytes`, `blobToBytes` |
| CSS         | `css/*`       | `toRGB`、`toCSSVariable`、`toCSSRGBVariable`   |
| Canvas      | `canvas`      | `measureText`                                  |
| Text truncation | `truncated` | `truncated` |
| Requests | `fetch` | `toCurl` |
| Scrolling | `nearest` | `nearestScrollable` |
| Fingerprints | `fingerprint` | `projection` |

See the [guide](/docs/host/guide) for individual APIs or [examples](/docs/host/examples) for reusable snippets.
