## 守卫

子路径：`guard/is-*`

守卫统一放在 `guard/is-*` 子路径下，覆盖环境探测、DOM/元素类型、Body/二进制类型、字符串格式等场景。

UA 类守卫默认读取 `navigator.userAgent`（或 `location.hostname`），也可传入字符串以便在 SSR 或单元测试中注入。

### isAndroid

断言 UA 是否表示 Android 系统。

```ts
const isAndroid = (ua?: string): boolean;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `ua` | `string` | 可选 UA 字符串，默认 `navigator.userAgent` |

| 返回 | 说明 |
| --- | --- |
| `boolean` | UA 含 `android`（不区分大小写）时为 `true` |

```ts
import { isAndroid } from '@momots/host/guard/is-android';

isAndroid(); // 当前环境
```

## 存储

子路径：`storage`

### memory

基于 `@momots/core` 的 `singleton` 创建的全局 `MemoryStorage` 单例。`Storagefy` 在 `localStorage` 不可用时自动降级到此实例。

### MemoryStorage

实现了 `Storage` 接口的内存版（基于 `Map`），常用于测试或降级。

```ts
class MemoryStorage implements Storage {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
  removeItem(key: string): void;
  clear(): void;
  key(index: number): string | null;
  get length(): number;
}
```

### Storagefy&lt;T&gt;

类型化的同步存储单元。键存为 `Storagefy:<key>`，值包装为 `{ value, expired }` JSON。默认使用 `localStorage`，不可用时降级到 `memory`。过期时间单位为**秒**；变更时会派发 `StorageEvent`。

```ts
class Storagefy<T> {
  constructor(key: string, storage?: Realizable<Storage>);

  set(arg: T | ((old: T | null) => T), expires?: number): void;
  get(): T | null;
  remove(): void;

  static readonly namespace: 'Storagefy';
  static has(key: string, storage?: Storage): boolean;
  static keys(storage?: Storage): string[];
  static used(storage?: Storage): number;
  static clear(storage?: Storage): void;
  static isNativeStorage: (storage: Storage) => boolean;
  static dispatch: (...args) => void;
}
```

| 实例方法 | 说明 |
| --- | --- |
| `set(arg, expires?)` | 写入值或函数式更新；`expires` 为过期秒数 |
| `get()` | 读取值；过期或解析失败时自动删除并返回 `null` |
| `remove()` | 删除键并派发 `StorageEvent` |

| 静态方法 | 说明 |
| --- | --- |
| `has(key)` | 键是否存在 |
| `keys()` | 列出命名空间下所有键 |
| `used()` | 命名空间已用空间（KB） |
| `clear()` | 清除命名空间下所有数据 |

读到过期项、JSON 解析失败时会自动删除并返回 `null`；`set` 超配额会抛错。

```ts
import { Storagefy } from '@momots/host/storage';

const cache = new Storagefy<{ name: string }>('profile');
cache.set({ name: 'Momo' }, 300); // 5 分钟后过期
cache.get(); // => { name: 'Momo' } | null
```

### StoragefyAsync&lt;T&gt;

与 `Storagefy` 语义一致，但支持可插拔的**异步** encode/decode。默认用 `JSON.parse` / `JSON.stringify`；提供 `static createAES<T>(hexKey)` 构造 AES-GCM 编解码器。`hexKey` 必须是 AES 支持的 16、24 或 32 字节 key 的十六进制字符串（分别对应 32、48 或 64 个 hex 字符）。

```ts
class StoragefyAsync<T> {
  constructor(
    key: string,
    params?: {
      store?: Realizable<Storage>;
      encode?: (value: StoragefyValue<T>) => Promise<string> | string;
      decode?: (value: string) => Promise<StoragefyValue<T>> | StoragefyValue<T>;
    },
  );

  set(arg: T | ((old: T | null) => T), expires?: number): Promise<void>;
  get(): Promise<T | null>;
  remove(): void;

  static createAES<T>(hexKey: string | (() => Promise<string>)): Promise<Codec<T>>;
  // 静态方法同 Storagefy（namespace 为 StoragefyAsync）
}
```

```ts
import { StoragefyAsync } from '@momots/host/storage';

const codec = await StoragefyAsync.createAES<Data>(
  '00112233445566778899aabbccddeeff',
);
const cell = new StoragefyAsync<Data>('k', {
  encode: codec.encode,
  decode: codec.decode,
});
await cell.set(data);
await cell.get();
```

## 持久缓冲

子路径：`persistent`

### PersistentBuffer&lt;T&gt;

轻量的持久化 FIFO 缓冲。构造时从 storage 恢复，每次变更后同步写入。默认 storage 为 `memory` 单例；实际键名为 `${namespace}:${key}`，默认 namespace 为 `PersistentBuffer`。

```ts
interface PersistentBufferOptions {
  key: string;
  namespace?: string;
  storage?: Realizable<Storage>;
}

class PersistentBuffer<T> {
  constructor(options: PersistentBufferOptions);

  readonly key: string;
  get size(): number;

  push(...args: T[]): void;
  peekAll(): T[];
  drain(count: number): void;
  clear(): void;
}
```

| 方法 | 说明 |
| --- | --- |
| `push(...args)` | 追加元素到末尾 |
| `peekAll()` | 返回所有元素的副本 |
| `drain(count)` | 从头部移除 `count` 个已消费元素；超出大小时等效 `clear()` |
| `clear()` | 清空缓冲区 |

storage 损坏或写入失败时静默降级，不影响内存中的核心操作。

```ts
import { PersistentBuffer } from '@momots/host/persistent';
import { MemoryStorage } from '@momots/host/storage';

const buf = new PersistentBuffer<number>({ key: 'events', storage: new MemoryStorage() });
buf.push(1, 2, 3);
buf.peekAll(); // => [1, 2, 3]
buf.drain(2);  // 丢弃最早的 2 个，剩 [3]
```

## URL

子路径：`url`

### toSearchParams

将多种输入归一化为 `URLSearchParams`。在缺少 `URLSearchParams` 的宿主环境中，需要调用方自行提供 polyfill。

```ts
function toSearchParams(init: unknown): URLSearchParams | undefined;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `init` | `unknown` | 查询参数初始化值 |

| 返回 | 说明 |
| --- | --- |
| `URLSearchParams \| undefined` | 可构造时返回实例，否则 `undefined` |

| 输入类型 | 行为 |
| --- | --- |
| `URLSearchParams` | 原样返回 |
| `string` | `new URLSearchParams(string)` |
| `string[]` | 过滤含 `=` 的项、去空格后拼接解析 |
| 普通对象 | 值 `toString()`，丢弃 nullish 键 |
| 其他 | `undefined` |

```ts
import { toSearchParams } from '@momots/host/url';

toSearchParams('a=1&b=2')?.get('a');                          // => '1'
toSearchParams({ a: 1, b: undefined, c: false })?.toString(); // => 'a=1&c=false'
```

## CSS 颜色

子路径：`css/*`

### RGBColor

解析结果对象，含 `red`、`green`、`blue`、`alpha` 通道及 `toHex()`、`toString()` 方法。`toString` 可传入 `{ alpha }` 覆盖透明度。

```ts
interface RGBColor {
  red: number;
  green: number;
  blue: number;
  alpha: number;
  toHex(params?: Partial<RGBColor>): string;
  toString(params?: Partial<RGBColor>): string;
}
```

### toRGB

解析 CSS 颜色字符串为 `RGBColor`。支持 hex（含 alpha）、`rgb()/rgba()`（含百分比与 `/` alpha）、relative RGB、`color-mix(in srgb, ...)`、`transparent`。无法解析返回 `null`。

```ts
function toRGB(val?: string): RGBColor | null;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `val` | `string` | CSS 颜色字符串（可选） |

| 返回 | 说明 |
| --- | --- |
| `RGBColor \| null` | 解析成功返回颜色对象，否则 `null` |

```ts
import { toRGB } from '@momots/host/css/to-rgb';

toRGB('#0f08')?.toHex();                                // => '#00ff00'
toRGB('rgb(1 2 3 / 50%)')?.toString();                  // => 'rgba(1, 2, 3, 0.5)'
toRGB('color-mix(in srgb, #000000, #ffffff)')?.toHex(); // => '#808080'
```

### toCSSVariable

从计算样式读取 CSS 自定义属性值。

```ts
function toCSSVariable<T extends string>(
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `name` | `string` | CSS 变量名（如 `--brand`） |
| `params.initial` | `string` | 变量不存在或无值时的回退值 |
| `params.element` | `HTMLElement` | 计算样式的元素，默认 `document.body` |

| 返回 | 说明 |
| --- | --- |
| `string \| undefined` | 变量值或 `initial` |

```ts

```

```ts
toCSSRGBVariable('--brand')?.toString({ alpha: 0.5 });
```

## Canvas

子路径：`canvas`

### measureText

使用浏览器 `CanvasRenderingContext2D.measureText` 测量文本宽度，并额外加上 `x` 字宽四分之一作为经验补偿。该函数需要可用的 `document` 和 2D canvas context；SSR、Bun、Node 或禁用 Canvas 的环境会返回 `undefined`。

```ts
function measureText(
  text?: string,
  font?: Partial<Pick<CSSStyleDeclaration, 'fontStyle' | 'fontWeight' | 'fontSize' | 'fontFamily'>>,
): number | undefined;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `text` | `string` | 待测量文本；不是字符串时返回 `undefined` |
| `font.fontStyle` | `CSSStyleDeclaration['fontStyle']` | 可选字体样式，如 `italic` |
| `font.fontWeight` | `CSSStyleDeclaration['fontWeight']` | 可选字重，如 `600` |
| `font.fontSize` | `CSSStyleDeclaration['fontSize']` | 字号，默认 `10px` |
| `font.fontFamily` | `CSSStyleDeclaration['fontFamily']` | 字体族，默认 `sans-serif` |

| 返回 | 说明 |
| --- | --- |
| `number \| undefined` | 文本宽度像素值；无 Canvas 或文本无效时为 `undefined` |

```ts
import { measureText } from '@momots/host/canvas';

const width = measureText('Momo', {
  fontWeight: '600',
  fontSize: '16px',
  fontFamily: 'Inter, sans-serif',
});
```

## 请求转 cURL

子路径：`fetch`

### generate

cURL 命令各片段生成器，行为对齐 Chrome DevTools 的「Copy as cURL」。

```ts
const generate = {
  method(init?: RequestInit): string;
  header(init?: RequestInit): string | void;
  body(init?: RequestInit): Promise<string | void>;
  compress(init?: RequestInit): string;
};
```

| 方法 | 说明 |
| --- | --- |
| `method` | 生成 `-X` 参数；GET 不输出 |
| `header` | 生成 `-H` 参数；忽略 `content-length` |
| `body` | 生成 `--data-raw` / `--data-binary` / `-F`；FormData 中 Blob 以 `@filename` 占位 |
| `compress` | 存在 `accept-encoding` 时输出 `--compressed` |

### toCurl

把 `fetch` 请求参数转成多行 cURL 命令（行尾 `\` 续行 + 两空格缩进）。

```ts
function toCurl(uri: string | URL, init?: RequestInit): Promise<string>;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `uri` | `string \| URL` | 请求 URL |
| `init` | `RequestInit` | 可选 fetch 初始化参数 |

| 返回 | 说明 |
| --- | --- |
| `Promise<string>` | 完整 cURL 命令字符串 |

```ts
import { toCurl } from '@momots/host/fetch';

await toCurl('https://api.example.com/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: '{"name":"Momo"}',
});
// curl 'https://api.example.com/users' \
//   -X 'POST' \
//   -H 'content-type: application/json' \
//   --data-raw '{"name":"Momo"}'
```

## 浏览器指纹

根入口：`@momots/host`

子路径：`fingerprint`

### projection

综合 UA、语言、canvas/WebGL/audio、屏幕、字体、时区、导航计时等信息生成 SHA-1 指纹（小写 hex，40 位）。

```ts
function projection(): Promise<string>;
```

| 返回 | 说明 |
| --- | --- |
| `Promise<string>` | 40 位小写 hex 指纹字符串 |

部分浏览器禁用 Canvas 或限制 AudioContext 时会回退为 `no_canvas` / `no_audio` 等占位值，仍参与哈希。

```ts
import { projection } from '@momots/host';

const fp = await projection(); // => 40 位 hex
```
