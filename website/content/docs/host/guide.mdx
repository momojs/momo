欢迎查阅 `@momots/host` 的 API 参考。下文按 [能力地图](/docs/host#能力地图) 中的主题分类，逐函数列出签名、参数、返回值与示例。除特别说明外，所有 API 均可从根入口或对应子路径导入。

在 Bun 服务中，模块可以安全导入，但部分 API 会降级或采用服务端宿主语义。请先查看[运行时兼容性矩阵](/docs/host#运行时兼容性)，并优先使用子路径导入。这里的“安全导入”不等于 DOM、Canvas 或浏览器访客信息可用。

```ts
import { isMobile, measureText, Storagefy } from '@momots/host';
```

需要可复制的实战片段，请前往 [示例](/docs/host/examples)。

## 守卫

子路径：`guard/is-*`

守卫统一放在 `guard/is-*` 子路径下，覆盖环境探测、DOM/元素类型、Body/二进制类型、字符串格式等场景。

UA 类守卫默认读取 `navigator.userAgent`（或 `location.hostname`），也可传入字符串以便在 SSR 或单元测试中注入。在 Bun 服务中判断请求方设备时，应显式传入请求头中的 UA；默认值描述的是 Bun 服务自身。DOM 类守卫在没有 DOM 的环境中安全返回 `false`，Web API 类守卫仍可正常判断 Bun 提供的对象。

### isAndroid

断言 UA 是否表示 Android 系统。

**社区对照：** [UAParser.js 的 `getOS()`](https://docs.uaparser.dev/api/main/get-os.html) 返回系统名称与版本；`isAndroid` 只返回 Android 判定结果，适合简单条件分支，也可显式传入 UA 用于 SSR 或测试。

```ts
const isAndroid = (ua?: string): boolean;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `ua` | `string` | 可选 UA 字符串，默认 `navigator.userAgent` |

| 返回 | 说明 |
| --- | --- |
| `boolean` | UA 含 `android`（不区分大小写）时为 `true` |

```ts
import { isAndroid } from '@momots/host/guard/is-android';

isAndroid(); // 当前环境
```

### isIOS

根据 UA 判断是否 iOS 系统。

**社区对照：** [UAParser.js 的 `getOS()`](https://docs.uaparser.dev/api/main/get-os.html) 可解析系统名称与版本；`isIOS` 只检查 UA 中的 iOS 相关标记，适合布尔判断，不提供版本信息。

```ts
function isIOS(ua?: string): boolean;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `ua` | `string` | 可选 UA 字符串，默认 `navigator.userAgent` |

| 返回 | 说明 |
| --- | --- |
| `boolean` | UA 匹配 `ip(hone\|ad\|od)` 或 `ios` 时为 `true` |

```ts
import { isIOS } from '@momots/host/guard/is-ios';

isIOS('Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X)'); // => true
```

### isMobile

根据 UA 判断是否移动端。

**社区对照：** [UAParser.js](https://docs.uaparser.dev/v1/) 可解析设备类型、型号与厂商，[Bowser](https://github.com/bowser-js/bowser) 提供浏览器、系统与平台信息。`isMobile` 将常见移动端 UA 统一判为 `true`，不区分手机和平板；需要细分设备信息时可使用这些解析库。

```ts
function isMobile(ua?: string): boolean;
```

| 返回 | 说明 |
| --- | --- |
| `boolean` | UA 匹配 `android\|iphone\|ipad\|ipod\|mobile` 时为 `true` |

### isStorage

```ts
function isStorage(data: unknown): data is Storage;
```

判断是否为当前运行环境的原生 `Storage` 实例，例如 `localStorage` 或 `sessionStorage`。
`MemoryStorage` 等自定义实现返回 `false`；环境未提供 `Storage` 全局时也返回 `false`。
判断过程不会读取 `localStorage` 或 `sessionStorage`，不会触发这些全局属性的访问异常。

```ts
import { isStorage } from '@momots/host/guard/is-storage';

if (isStorage(value)) {
  // value 已收窄为 Storage
  console.log(value.length);
}
```

## 存储

子路径：`storage`

### memory

基于 `@momots/core` 的 `singleton` 创建的全局 `MemoryStorage` 单例。`Storagefy` 在运行时没有 `localStorage` 时使用此实例；访问已有 `localStorage` 被拒绝时直接抛出原始异常。

在 Bun 中，该单例只属于当前进程：不会跨进程或重启保留，也不会产生浏览器的跨标签页 `StorageEvent`。需要持久化时请显式注入实现了 `Storage` 接口的外部存储。

### MemoryStorage

实现了 `Storage` 接口的内存版（基于 `Map`），常用于测试或降级。

```ts
class MemoryStorage implements Storage {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
  removeItem(key: string): void;
  clear(): void;
  key(index: number): string | null;
  get length(): number;
}
```

### Storagefy&lt;T&gt;

类型化的同步存储单元。键存为 `Storagefy:<key>`，值包装为 `{ value, expired }` JSON。默认使用 `localStorage`，运行时没有该 API 时使用 `memory`；浏览器拒绝访问时直接抛错，不静默写入内存。需要内存存储时可显式传入 `MemoryStorage`。过期时间单位为**秒**；变更时会派发 `StorageEvent`。

**社区对照：** [localForage](https://github.com/localForage/localForage) 提供异步存储抽象，[idb-keyval](https://github.com/jakearchibald/idb-keyval) 提供基于 IndexedDB 的 Promise 键值存储。`Storagefy` 适合需要同步 `Storage` 读写、类型化值、过期时间与浏览器存储事件的场景；需要 IndexedDB 存储时可使用前述社区库。

```ts
class Storagefy<T> {
  constructor(key: string, storage?: Realizable<Storage>);

  readonly key: string;
  readonly storage: Storage;

  set(arg: Realizable<T, [T | null]>, expires?: number): void;
  expire(arg: Realizable<number, [T | null]>): void;
  get(): T | null;
  remove(): void;

  static readonly namespace: 'Storagefy';
  static has(key: string, storage?: Storage): boolean;
  static keys(storage?: Storage): string[];
  static used(storage?: Storage): number;
  static clear(storage?: Storage): void;
  static isNativeStorage: typeof isStorage;
  static dispatch: (...args) => void;
}
```

| 实例方法 | 说明 |
| --- | --- |
| `set(arg, expires?)` | 写入值或函数式更新；更新函数接收已解码的当前值，`expires` 为过期秒数 |
| `expire(arg)` | 更新现有值的过期秒数但不改变值；可根据已解码的当前值计算秒数，键不存在时不写入 |
| `get()` | 读取值；过期或解析失败时自动删除并返回 `null` |
| `remove()` | 删除键并派发 `StorageEvent` |

`Storagefy.isNativeStorage` 与 `StoragefyAsync.isNativeStorage` 均为 `isStorage` 的别名。
事件派发也使用该守卫：原生存储传入 `storageArea`，自定义存储传入 `null`。

| 实例属性 | 说明 |
| --- | --- |
| `key` | 带 `Storagefy:` 命名空间的实际存储键 |
| `storage` | 当前解析得到的底层 `Storage` 实例 |

| 静态方法 | 说明 |
| --- | --- |
| `has(key)` | 键是否存在 |
| `keys()` | 列出命名空间下所有键 |
| `used()` | 命名空间已用空间（KB） |
| `clear()` | 清除命名空间下所有数据 |

读到过期项、JSON 解析失败时会自动删除并返回 `null`；`set` 超配额会抛错。

```ts
import { Storagefy } from '@momots/host/storage';

const cache = new Storagefy<{ name: string }>('profile');
cache.set({ name: 'Momo' }, 300); // 5 分钟后过期
cache.expire(600); // 保留当前值，将过期时间刷新为 10 分钟后
cache.get(); // => { name: 'Momo' } | null
```

### StoragefyAsync&lt;T&gt;

与 `Storagefy` 语义一致，但支持可插拔的**异步** encode/decode。默认用 `JSON.parse` / `JSON.stringify`；提供 `static createAES<T>(hexKey)` 构造 AES-GCM 编解码器。`hexKey` 必须是 AES 支持的 16、24 或 32 字节 key 的十六进制字符串（分别对应 32、48 或 64 个 hex 字符）。

**社区对照：** [localForage](https://github.com/localForage/localForage) 和 [idb-keyval](https://github.com/jakearchibald/idb-keyval) 用异步 API 访问底层存储。`StoragefyAsync` 的异步部分用于编解码，例如 AES-GCM 加解密；底层仍要求同步 `Storage` 接口，不能直接传入这些库的异步存储实例。

```ts
class StoragefyAsync<T> {
  constructor(
    key: string,
    params?: {
      store?: Realizable<Storage>;
      encode?: (value: StoragefyValue<T>) => Promise<string> | string;
      decode?: (value: string) => Promise<StoragefyValue<T>> | StoragefyValue<T>;
    },
  );

  set(arg: Realizable<T, [T | null]>, expires?: number): Promise<void>;
  expire(arg: Realizable<number, [T | null]>): Promise<void>;
  get(): Promise<T | null>;
  remove(): void;

  static createAES<T>(hexKey: string | (() => Promise<string>)): Promise<Codec<T>>;
  // 静态方法同 Storagefy（namespace 为 StoragefyAsync）
}
```

```ts
import { StoragefyAsync } from '@momots/host/storage';

const codec = await StoragefyAsync.createAES<Data>(
  '00112233445566778899aabbccddeeff',
);
const cell = new StoragefyAsync<Data>('k', {
  encode: codec.encode,
  decode: codec.decode,
});
await cell.set(data);
await cell.expire(600);
await cell.get();
```

`StoragefyAsync.expire()` 会使用实例配置的 `decode` / `encode` 重新写入条目，因此 AES 等自定义编解码器仍会保持原有存储格式。

## 持久缓冲

子路径：`persistent`

### PersistentBuffer&lt;T&gt;

轻量的持久化 FIFO 缓冲。构造时从 storage 恢复，每次变更后同步写入。默认 storage 为 `memory` 单例；实际键名为 `${namespace}:${key}`，默认 namespace 为 `PersistentBuffer`。

“持久”指相对于所注入 storage 的持久性。Bun 中采用默认 `memory` 时仍是进程内缓冲，不跨重启或多进程共享。

```ts
interface PersistentBufferOptions {
  key: string;
  namespace?: string;
  storage?: Realizable<Storage>;
}

class PersistentBuffer<T> {
  constructor(options: PersistentBufferOptions);

  readonly key: string;
  get size(): number;

  push(...args: T[]): void;
  peekAll(): T[];
  drain(count: number): void;
  clear(): void;
}
```

| 方法 | 说明 |
| --- | --- |
| `push(...args)` | 追加元素到末尾 |
| `peekAll()` | 返回所有元素的副本 |
| `drain(count)` | 从头部移除 `count` 个已消费元素；超出大小时等效 `clear()` |
| `clear()` | 清空缓冲区 |

storage 损坏或写入失败时静默降级，不影响内存中的核心操作。

```ts
import { PersistentBuffer } from '@momots/host/persistent';
import { MemoryStorage } from '@momots/host/storage';

const buf = new PersistentBuffer<number>({ key: 'events', storage: new MemoryStorage() });
buf.push(1, 2, 3);
buf.peekAll(); // => [1, 2, 3]
buf.drain(2);  // 丢弃最早的 2 个，剩 [3]
```

## 文本截断

子路径：`truncated`，也可以从 `@momots/host` 根入口导入。

### truncated

按像素宽度从中间截断文本，保留开头和结尾。测量使用完整候选文本的原始 Canvas 宽度，不叠加经验补偿；字符数量按字素簇计算，不拆分 emoji 或组合字符。

```ts
type TruncatedParams = {
  width?: number;
  font?: string;
  ellipsis?: string;
  tail?: number | { min: number };
};

function truncated(text: string, params?: TruncatedParams): string;
```

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `width` | `Infinity` | 结果的最大像素宽度；`NaN` 也视为不限制 |
| `font` | `'10px sans-serif'` | 用于测量的 CSS font 字符串 |
| `ellipsis` | `'...'` | 中间省略符，可以为空字符串 |
| `tail` | 未指定 | 数字表示固定保留的尾部字素数；`{ min }` 表示均分时尾部至少保留的字素数；未指定时均分 |

宽度限制优先于尾部保留数量；尾部放不下时会减少，连省略符都放不下时返回空字符串。保留数量向下取整，负数及非有限值按 `0` 处理。原文能放下、未限制宽度或当前环境无法测量时返回原文。

```ts
import { truncated } from '@momots/host/truncated';

const filename = 'very-long-filename.txt';
const fixedTail = truncated(filename, {
  width: 160,
  font: '16px Arial',
  tail: 4,
});
const minimumTail = truncated(filename, {
  width: 160,
  font: '16px Arial',
  tail: { min: 4 },
});
```

## 请求转 cURL

子路径：`fetch`

### toCurl

把 `fetch` 请求参数转成多行 cURL 命令（行尾 `\` 续行 + 两空格缩进）。

**工具对照：** [Chrome DevTools 的 Copy as cURL](https://developer.chrome.com/docs/devtools/network/reference/) 可从 Network 面板复制已记录的请求；`toCurl` 根据调用方提供的 URL 和 `RequestInit` 生成命令，适合在应用内提供复制入口，不会自动补齐浏览器实际发送的 Cookie 或其他请求头。[qs](https://github.com/ljharb/qs/blob/main/README.md) 负责查询串解析与序列化；需要嵌套查询参数时，可先用它构造 URL，再交给 `toCurl`。

```ts
function toCurl(uri: string | URL, init?: RequestInit): Promise<string>;
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `uri` | `string \| URL` | 请求 URL |
| `init` | `RequestInit` | 可选 fetch 初始化参数 |

| 返回 | 说明 |
| --- | --- |
| `Promise<string>` | 完整 cURL 命令字符串 |

`body: URLSearchParams` 按原生 Fetch 表单请求体序列化，保留参数顺序、重复键与空值。
这与 Drive 的显式 `body` 通道一致；Drive 的 `query` 和自动 `data: URLSearchParams`
通道由 Drive 自身合并到 URL，调用 `toCurl` 时应传入已经编码完成的 URL 和请求参数。

FormData 文本中的 `@`、`<`、`;type=` 按字面值发送，换行按 Fetch 规范化为 CRLF。
文件名按 cURL multipart 语法转义。无法用该命令语法准确表达的含 `=` 字段名、
含 NUL 的表单文本会抛出 `TypeError`；文件 MIME 类型支持主类型及可选的 charset 参数。

`Blob`、非共享 `ArrayBuffer`、TypedArray 和 DataView 使用 `--data-binary @文件`。
`File` 引用 `./<文件名>`；其余二进制 body 和含 NUL 的文本引用 `./body.bin`。
这些是文件引用：执行命令前需将原始字节保存到对应文件，`toCurl` 不自动创建文件。
TypedArray / DataView 只需保存其 `byteOffset` / `byteLength` 范围，文本按 UTF-8 保存。
FormData 中的 File 同样需要提前保存；匿名 Blob 的文件名由 FormData 提供。

共享 buffer 及其视图、ReadableStream 会抛出 `TypeError`，避免生成丢失 body 的命令。
函数不会消费或锁定传入的 ReadableStream。

```ts
import { toCurl } from '@momots/host/fetch';

await toCurl('https://api.example.com/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: '{"name":"Momo"}',
});
// curl 'https://api.example.com/users' \
//   -X 'POST' \
//   -H 'content-type: application/json' \
//   --data-raw '{"name":"Momo"}'
```

## 浏览器指纹

根入口：`@momots/host`

子路径：`fingerprint`

### projection

综合 UA、语言、canvas/WebGL/audio、屏幕、字体、时区、导航计时等信息生成 SHA-1 指纹（小写 hex，40 位）。

在 Bun 中该函数仍可执行，但生成的是服务端宿主/进程特征，不代表发起请求的浏览器访客。访客指纹应在浏览器端生成后再提交给服务端。

```ts
function projection(): Promise<string>;
```

| 返回 | 说明 |
| --- | --- |
| `Promise<string>` | 40 位小写 hex 指纹字符串 |

部分浏览器禁用 Canvas 或限制 AudioContext 时会回退为 `no_canvas` / `no_audio` 等占位值，仍参与哈希。

音频信息仅读取 AudioContext 的采样率，不创建或启动音频节点。创建的 AudioContext
会在读取成功或失败后尝试关闭，`projection()` 等待异步关闭完成；关闭失败不会中断指纹生成。

```ts
import { projection } from '@momots/host';

const fp = await projection(); // => 40 位 hex
```
