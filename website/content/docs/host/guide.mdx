Welcome to the `@momots/host` API reference. Topics follow the [capability map](/docs/host#capability-map), with signatures, parameters, return values, and examples for each function. Unless stated otherwise, APIs are available from the root and corresponding subpaths.

Modules are safe to import in Bun services, but some APIs degrade or use server-host semantics. Check the [runtime compatibility matrix](/docs/host#runtime-compatibility) first and prefer subpath imports. Safe import does not mean DOM, Canvas, or browser-visitor data is available.

```ts
import { isMobile, measureText, Storagefy } from '@momots/host';
```

For reusable practical snippets, see [examples](/docs/host/examples).

## Guards

Subpath: `guard/is-*`

Guards live under `guard/is-*`, covering environment detection, DOM/element types, body/binary types, and string formats.

UA guards default to `navigator.userAgent` (or `location.hostname`) and accept explicit strings for SSR and tests. To detect a requester's device in Bun, pass the request UA header; the default describes Bun itself. DOM guards safely return `false` without a DOM, while Web API guards recognize objects provided by Bun.

### isAndroid

Check whether a UA identifies Android.

**Community comparison:** [UAParser.js `getOS()`](https://docs.uaparser.dev/api/main/get-os.html) returns OS name and version; `isAndroid` returns only a boolean for simple branches and accepts explicit UA input for SSR or tests.

```ts

```

| Parameter | Type | Description |
| --- | --- | --- |
| `ua` | `string` | Optional UA string, default `navigator.userAgent` |

| Return | Description |
| --- | --- |
| `boolean` | `true` when the UA contains `android`, case-insensitively |


## Storage

Subpath: `storage`

### memory

A global `MemoryStorage` singleton created with `@momots/core`'s `singleton`. `Storagefy` uses it when `localStorage` is absent; denied access to existing `localStorage` propagates the original exception.

In Bun, this singleton belongs only to the current process: it does not survive restarts, span processes, or emit browser cross-tab `StorageEvent`s. For persistence, explicitly inject external storage implementing `Storage`.

### MemoryStorage

An in-memory `Storage` implementation backed by `Map`, useful for tests and fallback.

```ts
class MemoryStorage implements Storage {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
  removeItem(key: string): void;
  clear(): void;
  key(index: number): string | null;
  get length(): number;
}
```

### Storagefy&lt;T&gt;

A typed synchronous storage unit. Keys are stored as `Storagefy:<key>` and values as `{ value, expired }` JSON. Defaults to `localStorage`, falling back to `memory` only if the API is absent; browser access denial throws instead of silently using memory. Pass `MemoryStorage` explicitly when desired. Expiration is in **seconds**; changes dispatch `StorageEvent`.

**Community comparison:** [localForage](https://github.com/localForage/localForage) offers asynchronous storage abstractions; [idb-keyval](https://github.com/jakearchibald/idb-keyval) offers Promise-based IndexedDB key/value storage. `Storagefy` suits synchronous `Storage`, typed values, expiration, and browser storage events. Use those community libraries for IndexedDB storage.

```ts
class Storagefy<T> {
  constructor(key: string, storage?: Realizable<Storage>);

  readonly key: string;
  readonly storage: Storage;
  get snapshot(): T | null;

  set(arg: Realizable<T, [T | null]>, expires?: number): void;
  expire(arg: Realizable<number, [T | null]>): void;
  get(): T | null;
  subscribe(listener: () => void): () => void;
  remove(): void;

  static readonly namespace: 'Storagefy';
  static has(key: string, storage?: Storage): boolean;
  static keys(storage?: Storage): string[];
  static used(storage?: Storage): number;
  static clear(storage?: Storage): void;
  static isNativeStorage: typeof isStorage;
  static dispatch: (...args) => void;
}
```

| Instance method | Description |
| --- | --- |
| `set(arg, expires?)` | Write a value or functional update; the updater receives the decoded current value, and `expires` is seconds to expiration |
| `expire(arg)` | Update expiration without changing the value; may derive seconds from the decoded current value; does not write if the key is absent |
| `get()` | Read a value; delete expired or unparseable entries and return `null` |
| `subscribe(listener)` | Subscribe to changes for the same underlying storage instance and key; returns unsubscribe without immediate notification |
| `remove()` | Delete the key and dispatch `StorageEvent` |

`Storagefy.isNativeStorage` and `StoragefyAsync.isNativeStorage` are aliases of `isStorage`.
Event dispatch uses this guard too: native storage supplies `storageArea`, custom storage supplies `null`.

| Instance property | Description |
| --- | --- |
| `key` | Actual storage key with the `Storagefy:` namespace |
| `storage` | Currently resolved underlying `Storage` instance |
| `snapshot` | Read-only accessor for a side-effect-free snapshot; reuses object references when raw content is unchanged; returns `null` for expired/unparseable entries without deleting them |

| Static method | Description |
| --- | --- |
| `has(key)` | Whether a key exists |
| `keys()` | List all keys in the namespace |
| `used()` | Namespace storage usage in KB |
| `clear()` | Remove all data in the namespace |

`get()` deletes expired or invalid-JSON entries and returns `null`; `set` throws when quota is exceeded.

```ts
import { Storagefy } from '@momots/host/storage';

const cache = new Storagefy<{ name: string }>('profile');
cache.set({ name: 'Momo' }, 300); // Expires in five minutes
cache.expire(600); // Keep the value; reset expiration to ten minutes from now
cache.get(); // => { name: 'Momo' } | null
```

Combine `snapshot` with `subscribe()` to connect UI or external subscription systems.
Treat snapshot objects as read-only. Reading `snapshot` skips `get()` logging and deletion and starts no
expiration timer; expiration is checked on the next snapshot read.

```ts
const unsubscribe = cache.subscribe(() => {
  console.log(cache.snapshot);
});
// When no longer needed: unsubscribe();
```

Subscriptions bind to the underlying `Storage` instance and full key, not a particular `Storagefy` object.
Changes through `set()`, `remove()`, `expire()`, and `Storagefy.clear()` synchronously notify subscribers in the same
runtime, including `MemoryStorage` without browser event APIs.
Browsers also listen for same-storage-area events from other documents, including the null-key event from native `clear()`.
Direct calls to underlying `Storage` methods in the current page do not notify automatically. Write through `Storagefy`
or call `Storagefy.dispatch()` afterward.
With a storage resolver, keep the underlying instance stable for a subscription; resubscribe when changing instances.

### StoragefyAsync&lt;T&gt;

Read/write and expiration semantics match `Storagefy`, but codecs can be **asynchronous**, without synchronous `snapshot` / `subscribe()` APIs. Defaults to `JSON.parse` / `JSON.stringify`; `static createAES<T>(hexKey)` creates AES-GCM codecs. `hexKey` must encode a supported 16-, 24-, or 32-byte AES key as hex (32, 48, or 64 hex characters).

**Community comparison:** [localForage](https://github.com/localForage/localForage) and [idb-keyval](https://github.com/jakearchibald/idb-keyval) access underlying storage asynchronously. `StoragefyAsync` uses asynchrony for encoding/decoding, such as AES-GCM encryption; it still requires a synchronous `Storage` interface and cannot directly accept those libraries' asynchronous storage instances.

```ts
class StoragefyAsync<T> {
  constructor(
    key: string,
    params?: {
      store?: Realizable<Storage>;
      encode?: (value: StoragefyValue<T>) => Promise<string> | string;
      decode?: (value: string) => Promise<StoragefyValue<T>> | StoragefyValue<T>;
    },
  );

  set(arg: Realizable<T, [T | null]>, expires?: number): Promise<void>;
  expire(arg: Realizable<number, [T | null]>): Promise<void>;
  get(): Promise<T | null>;
  remove(): void;

  static createAES<T>(hexKey: string | (() => Promise<string>)): Promise<Codec<T>>;
  // Static methods match Storagefy (namespace: StoragefyAsync)
}
```

```ts
import { StoragefyAsync } from '@momots/host/storage';

const codec = await StoragefyAsync.createAES<Data>(
  '00112233445566778899aabbccddeeff',
);
const cell = new StoragefyAsync<Data>('k', {
  encode: codec.encode,
  decode: codec.decode,
});
await cell.set(data);
await cell.expire(600);
await cell.get();
```

`StoragefyAsync.expire()` rewrites entries using the configured `decode` / `encode`, preserving formats such as AES.

## Persistent buffers

Subpath: `persistent`

### PersistentBuffer&lt;T&gt;

A lightweight persistent FIFO buffer. Restores from storage on construction and writes synchronously after each change. Storage defaults to the `memory` singleton; actual keys are `${namespace}:${key}`, with default namespace `PersistentBuffer`.

Persistence is relative to the injected storage. Default `memory` in Bun is still process-local and neither survives restarts nor spans processes.

```ts
interface PersistentBufferOptions {
  key: string;
  namespace?: string;
  storage?: Realizable<Storage>;
}

class PersistentBuffer<T> {
  constructor(options: PersistentBufferOptions);

  readonly key: string;
  get size(): number;

  push(...args: T[]): void;
  peekAll(): T[];
  drain(count: number): void;
  clear(): void;
}
```

| Method | Description |
| --- | --- |
| `push(...args)` | Append items |
| `peekAll()` | Return a copy of all items |
| `drain(count)` | Remove `count` consumed items from the front; counts beyond size behave like `clear()` |
| `clear()` | Empty the buffer |

Corrupt storage or write failures degrade silently without affecting core in-memory operations.

```ts
import { PersistentBuffer } from '@momots/host/persistent';
import { MemoryStorage } from '@momots/host/storage';

const buf = new PersistentBuffer<number>({ key: 'events', storage: new MemoryStorage() });
buf.push(1, 2, 3);
buf.peekAll(); // => [1, 2, 3]
buf.drain(2);  // Discard the oldest two items, leaving [3]
```

## CSS colors

Subpath: `css/*`

### RGBColor

A parsed color object with `red`, `green`, `blue`, and `alpha` channels plus `toHex()` and `toString()`. Pass `{ alpha }` to `toString` to override opacity.

```ts
interface RGBColor {
  red: number;
  green: number;
  blue: number;
  alpha: number;
  toHex(params?: Partial<RGBColor>): string;
  toString(params?: Partial<RGBColor>): string;
}
```

### toRGB

Parse a CSS color string into `RGBColor`. Supports hex with alpha, `rgb()/rgba()` with percentages and `/` alpha, relative RGB, `color-mix(in srgb, ...)`, and `transparent`. Returns `null` on failure.

```ts
function toRGB(val?: string): RGBColor | null;
```

| Parameter | Type | Description |
| --- | --- | --- |
| `val` | `string` | Optional CSS color string |

| Return | Description |
| --- | --- |
| `RGBColor \| null` | Parsed color object, or `null` |

```ts
import { toRGB } from '@momots/host/css/to-rgb';

toRGB('rgb(1 2 3 / 50%)')?.toString();                  // => 'rgba(1, 2, 3, 0.5)'
toRGB('color-mix(in srgb, #000000, #ffffff)')?.toHex(); // => '#808080'
```

### measureText

Measure text with browser `CanvasRenderingContext2D.measureText`, adding one quarter of the width of `x` as an empirical adjustment. Requires `document` and a 2D canvas context; returns `undefined` in SSR, Bun, Node, or environments with Canvas disabled.

```ts
function measureText(
  text?: string,
  font?: Partial<Pick<CSSStyleDeclaration, 'fontStyle' | 'fontWeight' | 'fontSize' | 'fontFamily'>>,
): number | undefined;
```

| Parameter | Type | Description |
| --- | --- | --- |
| `text` | `string` | Text to measure; non-strings return `undefined` |
| `font.fontStyle` | `CSSStyleDeclaration['fontStyle']` | Optional font style, such as `italic` |
| `font.fontWeight` | `CSSStyleDeclaration['fontWeight']` | Optional weight, such as `600` |
| `font.fontSize` | `CSSStyleDeclaration['fontSize']` | Font size, default `10px` |
| `font.fontFamily` | `CSSStyleDeclaration['fontFamily']` | Font family, default `sans-serif` |

| Return | Description |
| --- | --- |
| `number \| undefined` | Width in pixels; `undefined` without Canvas or for invalid text |

```ts
import { measureText } from '@momots/host/canvas';

const width = measureText('Momo', {
  fontWeight: '600',
  fontSize: '16px',
  fontFamily: 'Inter, sans-serif',
});
```

## Text truncation

Subpath: `truncated`; also available from the `@momots/host` root.

### truncated

Truncate text in the middle by pixel width, retaining the beginning and end. Measurement uses the full candidate's raw Canvas width without empirical adjustment. Counts use grapheme clusters, preserving emoji and combining characters.

```ts
type TruncatedParams = {
  width?: number;
  font?: string;
  ellipsis?: string;
  tail?: number | { min: number };
};

function truncated(text: string, params?: TruncatedParams): string;
```

| Parameter | Default | Description |
| --- | --- | --- |
| `width` | `Infinity` | Maximum pixel width; `NaN` also means unlimited |
| `font` | `'10px sans-serif'` | CSS font string for measurement |
| `ellipsis` | `'...'` | Middle ellipsis; may be empty |
| `tail` | Unspecified | Number fixes the retained trailing grapheme count; `{ min }` sets a minimum when splitting evenly; unspecified splits evenly |

Width takes precedence over retained tail length; reduce the tail when necessary and return an empty string if even the ellipsis does not fit. Counts are floored; negative or nonfinite values become `0`. Return the original text if it fits, width is unlimited, or measurement is unavailable.

```ts
import { truncated } from '@momots/host/truncated';

const filename = 'very-long-filename.txt';
const fixedTail = truncated(filename, {
  width: 160,
  font: '16px Arial',
  tail: 4,
});
const minimumTail = truncated(filename, {
  width: 160,
  font: '16px Arial',
  tail: { min: 4 },
});
```

## Convert requests to cURL

Subpath: `fetch`

### toCurl

Convert `fetch` arguments into multiline cURL commands with trailing `\` continuations and two-space indentation.

**Tool comparison:** [Chrome DevTools Copy as cURL](https://developer.chrome.com/docs/devtools/network/reference/) copies recorded Network-panel requests; `toCurl` generates commands from a supplied URL and `RequestInit` for in-app copy controls, without automatically filling browser-sent cookies or headers. [qs](https://github.com/ljharb/qs/blob/main/README.md) parses and serializes query strings; construct nested query URLs with it before passing them to `toCurl`.

```ts
function toCurl(uri: string | URL, init?: RequestInit): Promise<string>;
```

| Parameter | Type | Description |
| --- | --- | --- |
| `uri` | `string \| URL` | Request URL |
| `init` | `RequestInit` | Optional Fetch initialization |

| Return | Description |
| --- | --- |
| `Promise<string>` | Complete cURL command |

`body: URLSearchParams` serializes as a native Fetch form body, preserving parameter order, duplicate keys, and empty values.
This matches Drive's explicit `body` channel. Drive merges `query` and automatic `data: URLSearchParams`
into the URL itself; pass the already encoded URL and request options to `toCurl`.

FormData text containing `@`, `<`, or `;type=` is sent literally; line endings normalize to CRLF as in Fetch.
Filenames are escaped for cURL multipart syntax. Field names containing `=` and form text containing NUL cannot be represented faithfully and
throw `TypeError`. File MIME types support a primary media type and optional charset parameter.

`Blob`, non-shared `ArrayBuffer`, TypedArray, and DataView use `--data-binary @file`.
`File` references `./<filename>`; other binary bodies and NUL-containing text reference `./body.bin`.
These are file references: save the original bytes to those files before execution; `toCurl` does not create them.
For TypedArray / DataView, save only the `byteOffset` / `byteLength` range; save text as UTF-8.
FormData Files must also be saved first; FormData supplies filenames for anonymous Blobs.

Shared buffers and views, and ReadableStream, throw `TypeError` rather than generating commands that lose the body.
The function does not consume or lock supplied ReadableStreams.

```ts
import { toCurl } from '@momots/host/fetch';

await toCurl('https://api.example.com/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: '{"name":"Momo"}',
});
// curl 'https://api.example.com/users' \
//   -X 'POST' \
//   -H 'content-type: application/json' \
//   --data-raw '{"name":"Momo"}'
```

## Browser fingerprints

Root entry: `@momots/host`

Subpath: `fingerprint`

### projection

Generate a SHA-1 fingerprint (40 lowercase hex characters) from UA, language, canvas/WebGL/audio, screen, fonts, timezone, navigation timing, and other information.

This function also runs in Bun, but identifies the server host/process, not the requesting browser visitor. Generate visitor fingerprints in the browser before sending them to the server.

```ts
function projection(): Promise<string>;
```

| Return | Description |
| --- | --- |
| `Promise<string>` | 40-character lowercase hexadecimal fingerprint |

When browsers disable Canvas or restrict AudioContext, placeholders such as `no_canvas` / `no_audio` still participate in the hash.

Audio information reads only the AudioContext sample rate; no audio nodes are created or started. The created AudioContext
is closed after reading succeeds or fails, and `projection()` awaits asynchronous closure; close failures do not interrupt fingerprint generation.

```ts
import { projection } from '@momots/host';

const fp = await projection(); // => 40 hex characters
```
