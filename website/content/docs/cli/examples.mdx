## 浏览器包

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: { target: 'browser' },
});
```

## Bun CLI 包

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    target: 'bun',
    executables: ['bin.js'],
  },
});
```

## 自定义构建步骤

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    scripts: ['lint', 'typecheck', 'types'],
    packages: 'bundle',
  },
});
```

## 内联指定依赖

其余声明依赖仍保持 external，只把列出的包打进产物：

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    bundle: ['@momots/host'],
  },
});
```

## 测试脚本

```json
{
  "scripts": {
    "test": "bun test src",
    "test:browser": "bun test browser-tests"
  },
  "devDependencies": {
    "bunwright": "^0.3.1"
  }
}
```

浏览器测试需要机器上已有 Chrome 或 WebKit；bunwright 不会下载浏览器。
