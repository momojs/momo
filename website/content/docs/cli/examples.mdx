## 浏览器包

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: { target: 'browser' },
});
```

## Bun CLI 包

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    target: 'bun',
    executables: ['bin.js'],
  },
});
```

## 自定义构建步骤

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    scripts: ['lint', 'typecheck', 'types'],
    packages: 'bundle',
  },
});
```

## 内联指定依赖

其余声明依赖仍保持 external，只把列出的包打进产物：

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    bundle: ['@momots/host'],
  },
});
```

## 验证内联依赖

构建时内联一个 workspace 包，并验证发布产物不再引用它：

```ts
import { defineConfig } from '@momots/cli';

export default defineConfig({
  build: {
    bundle: ['@momots/host'],
    splitting: true,
  },
  tarball: {
    forbidImports: ['@momots/host'],
    identities: [
      { export: 'Drive', from: ['.', './core'] },
    ],
  },
});
```

```json
{
  "scripts": {
    "test:tarball": "bun run build && momo tarball"
  }
}
```

使用 `momo tarball --keep` 可以保留临时消费项目；需要发布或手工检查 `.tgz` 时，使用 `momo tarball --destination ./artifacts`。

## 测试脚本

```json
{
  "scripts": {
    "test": "bun test src",
    "test:browser": "bun test browser-tests"
  },
  "devDependencies": {
    "bunwright": "^0.3.1"
  }
}
```

浏览器测试需要机器上已有 Chrome 或 WebKit；bunwright 不会下载浏览器。
