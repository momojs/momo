普通逻辑测试继续使用 `bun:test`。只有依赖 DOM、布局、Canvas 或浏览器全局对象的内容才需要 bunwright。

## 第 1 步：安装

```bash
bun add -d bunwright
```

bunwright 需要 Bun 1.3.12 或更高版本，以及本机已有的 Chrome 或 WebKit。

## 第 2 步：准备浏览器入口

浏览器不能直接导入本地 TypeScript 源码，因此先用 `Bun.build` 将待测模块打包。入口把浏览器内的操作暴露为可序列化的结果：

```ts
// browser-tests/fixture.ts
import { isScrollable } from '../src/is-scrollable';

globalThis.runBrowserCheck = () => {
  const box = document.createElement('div');
  box.style.cssText = 'height:100px;overflow:auto';
  box.innerHTML = '<div style="height:1000px"></div>';
  document.body.append(box);
  return isScrollable(box);
};
```

## 第 3 步：编写测试

```ts
// browser-tests/layout.test.ts
import { afterAll, beforeAll, expect, test } from 'bun:test';
import { browser } from 'bunwright';

let server: ReturnType<typeof Bun.serve>;
let page: Awaited<ReturnType<typeof browser.newPage>>;

beforeAll(async () => {
  const build = await Bun.build({
    entrypoints: [new URL('./fixture.ts', import.meta.url).pathname],
    target: 'browser',
  });
  if (!build.success) throw new Error('fixture build failed');

  server = Bun.serve({
    port: 0,
    fetch(request) {
      if (new URL(request.url).pathname === '/fixture.js') {
        return new Response(build.outputs[0]);
      }
      return new Response(
        '<script type="module" src="/fixture.js"></script>',
        { headers: { 'Content-Type': 'text/html' } },
      );
    },
  });

  page = await browser.newPage();
  await page.navigate(`http://${server.hostname}:${server.port}`);
});

afterAll(async () => {
  await browser.close();
  server.stop(true);
});

test('内容超高的容器是可滚动的', async () => {
  const result = await page.evaluate(() => globalThis.runBrowserCheck());
  expect(result).toBe(true);
});
```

## 第 4 步：运行

```json
{
  "scripts": {
    "test": "bun test src",
    "test:browser": "bun test browser-tests"
  }
}
```

```bash
bun run test
bun run test:browser
```

仓库里的 `@momots/host` 使用同样的结构：`bun:test` 负责测试报告和断言，bunwright 只负责真实浏览器页面。
