`@momots/refine` 提供号码校验和与公民身份号码解析。当前版本为
`0.1.0-alpha.0`，API 在 alpha 阶段仍可能调整。发布物包含 ESM 与 TypeScript
声明，可用于 Bun、Node.js 和浏览器打包器。

## 安装

```bash
bun add @momots/refine@alpha @momots/core@beta remeda type-fest
```

`@momots/core` 是 refine 的 peer dependency；`remeda`、`type-fest` 是 core 的
peer dependencies。`date-fns` 由 refine 自动安装。

## 入口

| 子路径 | API | 用途 |
| --- | --- | --- |
| 根入口 | `luhn`、`ISO`、`fromChinaIdCard`、`isValidChinaIdCard` | 常用工具 |
| `luhn` | `luhn` | Luhn 工具集合 |
| `luhn/card` | `card` | Luhn（MOD 10）校验 |
| `iso` | `ISO` | ISO 校验工具集合 |
| `iso/mod11-2` | `mod11_2` | 显式权重与映射的 MOD 11-2 校验 |
| `cn/idcard` | `fromChinaIdCard`、`isValidChinaIdCard`、`ChinaIdCardInfo` 类型 | 18 位公民身份号码 |

## Luhn 校验

```ts
import { card } from '@momots/refine/luhn/card';

card('79927398713'); // true
card('79927398714'); // false
card('059'); // true
card('4111 1111 1111 1111'); // false
```

完整输入包含校验位，必须至少两位 ASCII 数字。也支持非负安全整数，但前导零
和较长号码应使用字符串。空白、分隔符、小数及其他输入返回 `false`。

Luhn 仅检查校验和，不判断发卡机构、账号长度或实际分配情况；`00` 也满足
校验和。[IBM 文档](https://www.ibm.com/docs/en/gdp/11.4.0?topic=policies-special-pattern-tests)
说明了 Luhn 与号码格式检查的区别。

## MOD 11-2 校验

```ts
import { ISO } from '@momots/refine/iso';

const weights = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2];
const codes = ['1', '0', 'X', '9', '8', '7', '6', '5', '4', '3', '2'];

ISO.mod11_2('11010519491231002X', weights, codes); // true
ISO.mod11_2('11010519491231002x', weights, codes); // true
```

本体码必须全部为 ASCII 数字，`weights` 与其等长，元素为非负安全整数。
`codes` 按余数 0–10 列出 11 个单字符 ASCII 数字或字母，大小写不敏感。
数组可为 readonly；非法输入或参数内容返回 `false`。
调用方负责提供对应编码方案的权重和映射。

## 公民身份号码

```ts
import {
  fromChinaIdCard,
  isValidChinaIdCard,
} from '@momots/refine/cn/idcard';

const referenceDate = new Date(2026, 0, 1);
isValidChinaIdCard('11010519491231002x', referenceDate); // true
fromChinaIdCard('11010519491231002X', referenceDate);
// { region: '110105', date: '1949-12-31', age: 76, gender: 'F' }
```

18 位号码包含地址码、出生日期码、顺序码和校验码，参见
[北京市公安局说明](https://gaj.beijing.gov.cn/hudong/rddf/202003/t20200331_1771804.html)。
本包检查格式、校验位及出生日期，不支持旧 15 位号码。

- `isValidChinaIdCard(code: unknown, referenceDate?: Date)`：非法输入返回 `false`，支持末位 `x/X`。
- `fromChinaIdCard(code: string, referenceDate?: Date)`：检查通过后返回字段，非法输入抛出 `RangeError`。
- 出生日期必须存在且不晚于参考日期；无效参考日期也会被拒绝。
- 参考日期默认当前时间，年龄按运行环境的本地日历计算。显式传入日期可获得可重复的结果。
- 地址码返回六位原始字符串，年龄为周岁，性别码由顺序码奇偶性确定。
- 不自动清理空白，不核验行政区划真实性、实际发证或身份真实性。
