`Numeric` wraps Base UI Number Field with direct input, keyboard adjustments, increment/decrement buttons, and draggable labels. It preserves Base UI form, formatting, and validation features, uses momo semantic tokens for consistent sizes and states, and provides motion press feedback respecting reduced-motion preferences.

## Usage

```tsx
import { Numeric } from "@momots/design/components/numeric";

<Numeric
  label="Amount"
  value={amount}
  min={0}
  max={1000}
  step={5}
  onChange={setAmount}
/>
```

`label` automatically associates with the internal input. Drag it horizontally to adjust the value continuously, or click or hold the side buttons to increase or decrease by `step`.

## Uncontrolled values and formatting

```tsx
<Numeric
  label="Price"
  defaultValue={128}
  min={0}
  step={0.01}
  locale="zh-CN"
  format={{
    style: "currency",
    currency: "CNY",
  }}
/>
```

The input can be cleared, producing `null`. Use `onValueChange` to inspect the change reason, cancel a change, or read the underlying event. `onChange` is a simplified callback invoked only after a change has not been cancelled.

```tsx
<Numeric
  label="Quantity"
  value={quantity}
  onValueChange={(next, details) => {
    if (details.reason === "input-paste" && next !== null && next > 100) {
      details.cancel();
    }
  }}
  onChange={setQuantity}
/>
```

## Interaction

- **Input**: accepts the current locale's number format. By default, blur completes formatting and clamps the displayed value to the allowed range.
- **Keyboard**: arrow keys adjust by `step`; hold `Alt` for `smallStep` or `Shift` for `largeStep`. With `min` / `max`, `Home` / `End` jump to the boundaries.
- **Step buttons**: click or hold increment/decrement. The corresponding button is disabled automatically at `min` / `max`.
- **Draggable label**: drag the label horizontally to adjust the value continuously.
- **Wheel**: enable `allowWheelScrub` to adjust with the wheel while the input is focused and hovered.

`onValueCommitted` indicates that an edit has finished. Text input commits on blur; step buttons and label dragging commit on pointer release; keyboard and wheel interactions commit immediately after each value change.

## Range and form validation

By default, direct input is constrained by `min` / `max`, showing the corrected value after blur. With `allowOutOfRange`, directly entered values may remain outside the range after blur so native forms can report `rangeUnderflow` or `rangeOverflow`. Stepping interactions, including buttons, keyboard, wheel, and dragging, remain constrained to the range.

Place Numeric inside Base UI Field to associate descriptions and errors and pass invalid state to the input and group border:

```tsx
import { Field } from "@base-ui/react/field";
import { Numeric } from "@momots/design/components/numeric";

<Field.Root name="quantity" validationMode="onBlur">
  <Numeric
    label="Quantity"
    defaultValue={1}
    min={1}
    max={99}
    required
    allowOutOfRange
  />
  <Field.Description>Enter a quantity between 1 and 99.</Field.Description>
  <Field.Error match="valueMissing">Enter a quantity.</Field.Error>
  <Field.Error match="rangeUnderflow">Quantity must be at least 1.</Field.Error>
  <Field.Error match="rangeOverflow">Quantity must not exceed 99.</Field.Error>
</Field.Root>
```

Do not enable `allowOutOfRange` solely to show an error when retaining out-of-range input is unnecessary. Perform custom validation in `onValueChange`, or connect external form state through `Field.Root invalid`.

## Slots and animation

`scrubArea`, `scrubAreaCursor`, `group`, `input`, `decrement`, and `increment` accept slot configurations. A props object configures the default Base UI slot while preserving state attributes, keyboard interactions, and accessibility semantics. Base UI slot `className` also accepts a state callback; `input.nativeSize` sets the native character-width hint.

| Configuration | Behavior |
| --- | --- |
| Omitted / `true` | Enables the default node |
| `false` / `null` | Remove the node and its subtree |
| props object | Configure the default node; component-managed props such as size and container children take precedence |
| ReactNode | Replace the node entirely without automatically merging default props, events, or refs |

Removing or replacing `group` affects both the input and step buttons; removing or replacing `scrubArea` affects both the label and scrub cursor.

```tsx
<Numeric
  label="Seats"
  labelProps={{ className: "uppercase tracking-wide" }}
  input={{
    "aria-describedby": "seat-help",
    className: "text-end",
  }}
  decrement={{ "aria-label": "Decrease seats" }}
  increment={{ "aria-label": "Increase seats" }}
/>
```

Passing a ReactNode replaces the corresponding slot entirely. Callers must preserve the necessary Base UI primitives, events, and `aria` semantics themselves. Prefer a props object for ordinary style or native attribute adjustments.

Default step buttons use motion `whileTap` for press scaling and respect system reduced-motion settings through `MotionConfig reducedMotion="user"`. Replacing a button slot with a ReactNode also replaces its default press animation.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `label` | `ReactNode` | Required accessible label; also the draggable adjustment area |
| `labelProps` | Native label props | Configure the internal label; Numeric manages `children` and `htmlFor` |
| `value` | `number \| null` | Controlled value; `null` means the input is empty |
| `defaultValue` | `number` | Uncontrolled initial value |
| `size` | `"sm" \| "md" \| "lg"` | Control size; defaults to `"md"` |
| `min` / `max` | `number` | Minimum and maximum values |
| `step` | `number \| "any"` | Basic increment for buttons, arrows, and dragging; defaults to `1` |
| `smallStep` / `largeStep` | `number` | Steps for `Alt` / `Shift` modifiers; default to `0.1` / `10` |
| `format` | `Intl.NumberFormatOptions` | Number formatting options |
| `locale` | `Intl.LocalesArgument` | Number parsing and formatting locale; defaults to the runtime locale |
| `allowOutOfRange` | `boolean` | Keep directly entered out-of-range values after blur; stepping remains constrained |
| `allowWheelScrub` | `boolean` | Enable wheel adjustment when focused and hovered |
| `snapOnStep` | `boolean` | Snap to the nearest step multiple when incrementing or decrementing |
| `disabled` / `readOnly` / `required` | `boolean` | Disabled, read-only, and required states |
| `name` / `form` | `string` | Form field name and associated form |
| `onChange` | `(value: number \| null) => void` | Simplified callback for non-cancelled value changes |
| `onValueChange` | `(value: number \| null, details) => void` | Full value change callback with reason and cancellation support |
| `onValueCommitted` | `(value: number \| null, details) => void` | Edit commit callback on input blur, pointer release, or keyboard/wheel changes |
| `scrubArea` / `scrubAreaCursor` | `NumericProps['scrubArea']` / `NumericProps['scrubAreaCursor']` | Configure or replace the draggable area and scrub cursor |
| `group` / `input` | `NumericProps['group']` / `NumericProps['input']` | Configure or replace the input group and visible input; input also supports `nativeSize` |
| `decrement` / `increment` | `NumericProps['decrement']` / `NumericProps['increment']` | Configure or replace decrement/increment buttons |
| `className` | `string \| ((state) => string)` | Additional root styles; can read Number Field state |
| `id` | `string` | Visible input ID; the internal label associates with it automatically |
| `inputRef` | `React.Ref<HTMLInputElement>` | Access the hidden input Base UI uses for forms and validation |
| `render` | Base UI render prop | Compose or replace Root's underlying div |

Other Base UI Number Field Root props are forwarded to the internal Root.
