`TweenNumber` smoothly interpolates changed values with Motion `animate` and `useMotionValue`, formatting output with `Intl.NumberFormat`. It suits dashboards, counters, and monetary values.

<TweenNumberPlayground />

## Usage

```tsx
import { TweenNumber } from "@momots/design/components/tween-number";

<TweenNumber
  value={1280}
  locales="zh-CN"
  format={{
    style: "currency",
    currency: "CNY",
    minimumFractionDigits: 2,
    maximumFractionDigits: 2,
  }}
/>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `number \| string` | Target numeric value |
| `duration` | `number` | Transition duration in seconds; theme animation by default; `0` updates immediately |
| `format` | `Intl.NumberFormatOptions` | Number formatting options |
| `formatter` | `(value: number) => string` | Formats animated values, taking priority over `format` and `locales` |
| `locales` | `Intl.LocalesArgument` | Locale configuration; defaults to `zh-CN` |
| `transition` | `Transition` | Overrides Motion transition configuration |
| `className` | `string` | Additional Tailwind classes on the container |
| `...props` | `ComponentProps<typeof motion.span>` | Other `motion.span` props |
