`Dialog` wraps Base UI Dialog with focus trapping, scroll locking, dismissal by Escape or backdrop click, and focus restoration after closing. It uses momo semantic tokens for surfaces, borders, and typography and preserves Motion perspective, rotation, and blur enter/exit animations. With reduced motion enabled, only opacity changes remain.

## Usage

```tsx
import { useState } from "react";

import { Button } from "@momots/design/components/button";
import {
  Dialog,
  DialogClose,
} from "@momots/design/components/dialog";

function SyncSettings() {
  const [open, setOpen] = useState(false);

  return (
    <Dialog
      open={open}
      onChange={setOpen}
      trigger={<Button>Sync settings</Button>}
      title="Confirm sync settings"
      description="Review settings before applying them to the current workspace."
      footer={
        <>
          <DialogClose render={<Button variant="secondary" />}>
            Cancel
          </DialogClose>
          <Button onClick={() => setOpen(false)}>Apply settings</Button>
        </>
      }
    >
      Local changes are preserved first, with recovery copies created when conflicts occur.
    </Dialog>
  );
}
```

`trigger` is composed through Base UI's `Dialog.Trigger`, automatically receiving opening semantics, keyboard interactions, and `aria` attributes. `DialogClose` must be rendered inside the Dialog body or `footer`; it suits actions such as “Cancel” in uncontrolled dialogs.

## Uncontrolled state

Without `open`, Dialog manages its own state:

```tsx
<Dialog
  defaultOpen={false}
  trigger={<Button>View details</Button>}
  title="Sync details"
  description="The latest sync completed 2 minutes ago."
>
  24 items are synced, with no conflicts requiring attention.
</Dialog>
```

`onChange` is a simplified callback after a state change is accepted. Use `onOpenChange` to inspect the close reason, prevent a particular dismissal, or access the underlying event:

```tsx
<Dialog
  title="Edit draft"
  trigger={<Button>Open draft</Button>}
  onOpenChange={(nextOpen, details) => {
    if (!nextOpen && details.reason === "outside-press" && hasUnsavedChanges) {
      details.cancel();
    }
  }}
>
  ...
</Dialog>
```

## Content and focus

- `title` is required and always rendered by Base UI `Dialog.Title` as the popup's accessible name.
- `description` is rendered by `Dialog.Description` and automatically associated with the popup.
- The body scrolls independently when content exceeds the visible height, keeping the heading, close button, and footer actions visible.
- Opening focuses the first interactive element by default; closing returns focus to the trigger. Override this through `popupProps.initialFocus` / `popupProps.finalFocus`.
- With `modal={true}` or `modal="trap-focus"`, keep a visible close control inside the popup. If `showCloseButton={false}`, render `DialogClose` in the body or `footer`.
- `disablePointerDismissal` only prevents outside clicks from closing the popup. For control by dismissal reason, call `details.cancel()` in `onOpenChange`.

Use `AlertDialog` semantics for confirmation flows such as irreversible deletion or payments instead of treating an ordinary Dialog as an alert dialog.

## Content nodes

`title`, `description`, `children`, and `footer` follow shared [Content Slots](/docs/design/content-slots). Configure tags, attributes, and styles through `slots`:

```tsx
slots={{
  header: { render: <header /> },
  title: { render: <h3 />, className: "font-semibold" },
  content: { className: "space-y-3" },
  footer: { render: <footer /> },
}}
```

Omitting a slot uses its default node; `false` hides it. Base UI maintains heading and description accessibility associations.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `open` | `boolean` | Controlled open state |
| `defaultOpen` | `boolean` | Uncontrolled initial open state; defaults to `false` |
| `onChange` | `(open: boolean) => void` | Simplified callback after a non-cancelled state change |
| `onOpenChange` | Base UI callback | Full cancellable callback with `reason` and the underlying event |
| `trigger` | `ReactElement` | Trigger element composed through `Dialog.Trigger` |
| `title` | `ReactNode` | Required accessible title |
| `description` | `ReactNode` | Optional description |
| `children` | `ReactNode` | Scrollable body content |
| `footer` | `ReactNode` | Footer action area |
| `size` | `"sm" \| "md" \| "lg"` | Popup maximum width; defaults to `"md"` |
| `showCloseButton` | `boolean` | Show the top-right close button; defaults to `true` |
| `closeLabel` | `string` | Accessible name for the built-in close button |
| `closeIcon` | `ReactNode` | Replace the built-in close icon |
| `modal` | `boolean \| "trap-focus"` | Focus trapping, scroll locking, and outside interaction policy |
| `disablePointerDismissal` | `boolean` | Prevent outside clicks from closing the popup |
| `triggerProps` / `portalProps` | Base UI props | Underlying props forwarded to Trigger and Portal |
| `backdropProps` / `viewportProps` / `popupProps` | Base UI props | Underlying props for the backdrop, positioning layer, and popup |
| `closeProps` | Base UI props | Underlying props forwarded to the close node |
| `className` | `string` | Additional Tailwind classes for the Popup surface |
| `triggerClassName` / `backdropClassName` / `viewportClassName` | `string` | Styles for the corresponding outer slots |
| `slots` | `DialogProps['slots']` | Configure header, title, description, content, and footer nodes |
| `closeClassName` | `string` | Close button styles |

Other Base UI Dialog Root props are forwarded to the internal Root.
