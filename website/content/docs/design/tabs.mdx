`Tabs` 使用 Base UI Tabs 处理键盘导航和面板关联，组件 API 使用 `options` 描述 tab 与 panel。列表、指示器、面板与文本颜色消费 momo semantic token。

<TabsPlayground />

## 使用

```tsx
import { Tabs } from "@momots/design/components/tabs";

<Tabs
  value={tab}
  onChange={setTab}
  options={[
    { value: "overview", label: "Overview", content: "Overview panel" },
    { value: "settings", label: "Settings", content: "Settings panel" },
  ]}
/>;
```

## Props

| Prop           | 类型                         | 说明              |
| -------------- | ---------------------------- | ----------------- |
| `value`        | `T`                          | 当前 tab          |
| `defaultValue` | `T`                          | 非受控默认 tab    |
| `options`      | `TabOption<T>[]`             | tab 与 panel 描述 |
| `orientation`  | `"horizontal" \| "vertical"` | 排列方向          |
| `onChange`     | `(value: T) => void`         | 切换回调          |

## 选中状态与高度

非受控模式使用 `defaultValue` 初始化；未指定时选择第一个未禁用的选项，也支持初始为空、之后异步提供 `options`。已选项被移除时面板区域收起，同一选中值重新出现时恢复。

受控模式的 `onChange` 表达切换请求；父组件传回新的 `value` 后，面板和高度才跟随切换。当前面板的异步内容变化会持续触发高度测量，外层边框不计入动画高度，减少动态效果偏好下直接更新高度。

高度策略与测量约束见 [useAutoHeight](/docs/design/use-auto-height)。
