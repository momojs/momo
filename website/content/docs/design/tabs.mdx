`Tabs` uses Base UI Tabs for keyboard navigation and panel association, with `options` describing tabs and panels. List, indicator, panel, and text colors use momo semantic tokens.

<TabsPlayground />

## Usage

```tsx
import { Tabs } from "@momots/design/components/tabs";

<Tabs
  value={tab}
  onChange={setTab}
  options={[
    { value: "overview", label: "Overview", content: "Overview panel" },
    { value: "settings", label: "Settings", content: "Settings panel" },
  ]}
/>;
```

## Props

| Prop | Type | Description |
| -------------- | ---------------------------- | ----------------- |
| `value` | `T` | Current tab |
| `defaultValue` | `T` | Uncontrolled initial tab |
| `options` | `TabOption<T>[]` | Tab and panel definitions |
| `orientation` | `"horizontal" \| "vertical"` | Layout direction |
| `onChange` | `(value: T) => void` | Tab-change callback |

## Selection and height

Uncontrolled mode initializes from `defaultValue`, otherwise selecting the first enabled option. It also supports initially empty options loaded asynchronously. Removing the selected option collapses the panel area; restoring that value restores the panel.

Controlled `onChange` requests a selection; the panel and height change only when the parent supplies the new `value`. Async content changes keep triggering measurement. Outer borders are excluded from animated height, and reduced-motion preferences update height immediately.

See [useAutoSize](/docs/design/use-auto-size) for height strategies and measurement constraints.
