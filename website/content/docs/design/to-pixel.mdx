---
title: toPixel
description: Convert root-level rem spacing variables to pixel values for JavaScript.
icon: Ruler
---

`toPixel` supports JavaScript APIs requiring numeric dimensions. It reads a root CSS spacing variable, converts it using the root font size, and multiplies by the requested factor.

## Importing and calculating

```tsx
import { toPixel } from "@momots/design/tailwind";

// In a browser with a 16px root font size and --spacing: 0.25rem:
toPixel(4);   // 16
toPixel(1.5); // 6
toPixel(-2);  // -8
```

The calculation is `size × root font size in px × CSS variable value in rem`. The default variable is Tailwind's `--spacing`; another root variable expressed in `rem` can be supplied.

```ts
function toPixel(size: number, property?: string): number;
```

| Parameter | Description |
| --- | --- |
| `size` | Spacing multiplier, including fractional or negative values |
| `property` | CSS variable name; defaults to `"--spacing"` |

## Supported components

The current implementation uses `parseFloat` and always interprets the value as `rem`; callers must ensure correct units:

| Condition | Current behavior |
| --- | --- |
| Variable is `0.25rem`, root font size is `16px` | Each spacing unit becomes `4px` |
| Variable is `4px` or another non-rem unit | Still multiplied by root font size, producing an incorrect unit conversion |
| Variable missing, empty, or unresolved `calc(...)` | Cannot parse correctly and may return `NaN` |
| Variable exists only on a local container | Ignores the local value and always queries `document.documentElement` |
| Root font size or theme variable changes later | Existing results do not update; call again |

Use `toPixel` for loaded root-level spacing tokens expressed in `rem`. Prefer Tailwind classes or CSS variables for ordinary layouts. For arbitrary CSS lengths, measure actual element dimensions separately.

## SSR and first render

Servers cannot read computed styles, so the function returns raw `size` without pixel conversion. For example, `toPixel(4)` returns `4` on the server and `16` in the browser environment above.

For server-rendered pages, read styles after mounting so server and initial client render share one initial value:

```tsx
import { useEffect, useState } from "react";
import { toPixel } from "@momots/design/tailwind";

function MeasuredSpacing() {
  const [pixels, setPixels] = useState<number | null>(null);

  useEffect(() => {
    const value = toPixel(4);
    if (Number.isFinite(value)) setPixels(value);
  }, []);

  return <output>{pixels === null ? "Not measured" : `${pixels}px`}</output>;
}
```

This example assumes stylesheets load before mounting. For asynchronously loaded themes or changed root variables, recalculate after the change completes.
