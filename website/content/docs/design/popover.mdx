`Popover` combines Base UI Popover and Motion for forms, settings, and information related to a trigger. Non-modal by default, it supports collision avoidance, Esc/outside-click dismissal, focus restoration, and momo semantic styling.

<PopoverPlayground />

## Usage

```tsx
import { Button } from '@momots/design/components/button';
import { Input } from '@momots/design/components/input';
import { Popover, PopoverClose } from '@momots/design/components/popover';

<Popover
  trigger={<Button variant='outline'>Edit workspace</Button>}
  title='Workspace settings'
  description='Change the name shown in the workspace.'
  showArrow
  footer={
    <PopoverClose render={<Button size='sm' />}>Done</PopoverClose>
  }
>
  <label className='grid gap-momo-xs'>
    Workspace name
    <Input defaultValue='My workspace' />
  </label>
</Popover>
```

`trigger` composes through Base UI Trigger, preserving events, styles, and ref while adding opening semantics and keyboard interaction. `PopoverClose` must be in the Popover body or `footer`; compose it with momo Button through `render`.

## State and dismissal

Without `open`, the component manages its own state; `defaultOpen` sets the initial value. Controlled usage matches Dialog:

```tsx
const [open, setOpen] = useState(false);

<Popover
  open={open}
  onChange={setOpen}
  trigger={<Button>Open settings</Button>}
  title='Settings'
>
  ...
</Popover>
```

`onChange` receives uncanceled state-change requests; controlled callers still update `open`. Use `onOpenChange` to inspect dismissal reasons or prevent closing:

```tsx
<Popover
  trigger={<Button>Edit draft</Button>}
  title='Edit draft'
  onOpenChange={(nextOpen, details) => {
    if (!nextOpen && details.reason === 'outside-press' && hasUnsavedChanges) {
      details.cancel();
    }
  }}
>
  ...
</Popover>
```

## Positioning and animation

- `side` defaults to `bottom`, `align` to `center`, and `sideOffset` to `8`.
- `positionerProps` supports Base UI positioning options including `anchor`, `collisionBoundary`, `collisionPadding`, `collisionAvoidance`, and `positionMethod`. Same-name settings override top-level shorthand.
- `showArrow` defaults to off; arrows and scale origin follow the actual collision-adjusted position.
- `Positioner` handles placement; its inner `Popup` handles fading and slight scaling. Portal is removed after exit completes.
- Animation uses the shared `ui` motion preset. System reduced motion retains only opacity by default; theme `off` completes transitions immediately.
- `size` determines default width within available space. Override width with `className`; oversized body content scrolls independently.

## Content and focus

`title` and `description` automatically associate accessible name and description. Without a visible heading, provide an accessible name through `popupProps={{ 'aria-label': 'Workspace settings' }}`.

Opening normally focuses the first interactive descendant. Touch opening lets Base UI prefer the popup itself to avoid immediately showing the virtual keyboard. Closing restores focus; customize targets through `popupProps.initialFocus` and `popupProps.finalFocus`.

`modal` defaults to `false`. With `true` or `'trap-focus'`, retain a `PopoverClose` in the body or footer to enable the corresponding focus trap and give touch screen-reader users a way to close it.

Use Menu and Select semantics for menu-item navigation and option selection respectively.

## Content nodes

`title`, `description`, `children`, and `footer` follow shared [Content Slots](/docs/design/content-slots). Configure tags, attributes, and styles through `slots`:

```tsx
slots={{
  header: { render: <header /> },
  title: { render: <h3 />, className: "font-semibold" },
  content: { className: "space-y-3" },
  footer: { render: <footer /> },
}}
```

Omitting a slot uses its default node; `false` hides it. Base UI maintains heading and description accessibility associations.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `open` / `defaultOpen` | `boolean` | Controlled state / uncontrolled initial value; closed by default |
| `onChange` | `(open: boolean) => void` | Uncanceled state-change requests |
| `onOpenChange` | Base UI callback | Full cancelable event with reason |
| `trigger` | `ReactElement` | Trigger composed through Base UI Trigger |
| `title` / `description` | `ReactNode` | Optional heading and description |
| `children` / `footer` | `ReactNode` | Body and footer actions |
| `size` | `'sm' \| 'md' \| 'lg'` | Default widths 14 / 18 / 24rem; defaults to `'md'` |
| `side` | Base UI side | Defaults to `'bottom'`; supports four sides and logical directions |
| `align` | `'start' \| 'center' \| 'end'` | Defaults to `'center'` |
| `sideOffset` / `alignOffset` | `number \| function` | Side-axis / alignment-axis offset; defaults to 8 / 0 |
| `showArrow` | `boolean` | Shows the anchor arrow; defaults to `false` |
| `modal` | `boolean \| 'trap-focus'` | Outside interaction and focus policy; defaults to `false` |
| `triggerProps` / `portalProps` | Base UI props | Trigger and Portal props, including custom Portal containers |
| `positionerProps` / `popupProps` | Base UI props | Positioning and popup props, including focus configuration |
| `arrowProps` | Base UI props | Arrow node props |
| `className` | `string` | Popup surface styles |
| `triggerClassName` / `positionerClassName` / `arrowClassName` | `string` | Styles for corresponding nodes |
| `slots` | `PopoverProps['slots']` | Configuration for header, title, description, content, and footer |

Other Base UI Popover Root props are forwarded internally. `PopoverClose` accepts Base UI Close props, including `render`, `className`, and `ref`.
