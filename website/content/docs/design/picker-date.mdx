`PickerDate` 基于 `PickerCore` 生成 year/month/day 三列，面板、选中行、文本与 focus ring 使用 momo semantic token。

<PickerDatePlayground />

## 使用

```tsx
import { PickerDate } from "@momots/design/components/picker-date";

<PickerDate value={date} onChange={setDate} />
```

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `value` | `Date` | 受控日期 |
| `defaultDate` | `Date` | 非受控默认日期 |
| `min` | `Date` | 可选最小日期 |
| `max` | `Date` | 可选最大日期 |
| `disabled` | `boolean` | 是否禁用 |
| `className` | `string` | 根节点追加 Tailwind class |
| `onChange` | `(value: Date) => void` | 日期变化回调 |
