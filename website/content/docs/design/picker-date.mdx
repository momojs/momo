`PickerDate` builds date wheels with `PickerCore`. Its panel, selected row, text, and focus ring use momo semantic tokens. `precision` selects year, year/month, or full-date display.

<PickerDatePlayground />

## Usage

```tsx
import { PickerDate } from "@momots/design/components/picker-date";

<PickerDate value={date} onChange={setDate} />
```

`precision="year"` returns January 1 of the selected year; `precision="month"` returns the first day of the selected month; the default `precision="date"` returns the full date. `min` and `max` are compared at the same precision.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `Date` | Controlled date |
| `defaultDate` | `Date` | Uncontrolled initial date |
| `precision` | `"year" \| "month" \| "date"` | Date precision; defaults to `"date"` |
| `min` | `Date` | Optional minimum date |
| `max` | `Date` | Optional maximum date |
| `disabled` | `boolean` | Whether interaction is disabled |
| `className` | `string` | Additional Tailwind classes on the root |
| `onChange` | `(value: Date) => void` | Date change callback |
