`Dialog` 基于 Base UI Dialog 封装，提供焦点圈定、滚动锁定、Esc / 点击遮罩关闭和关闭后的焦点恢复。组件使用 momo semantic token 组织表面、边框与文字样式，并保留 Motion 的透视、旋转与模糊进入/退出动画；系统开启 reduced motion 时只保留透明度变化。

## 使用

```tsx
import { useState } from "react";

import { Button } from "@momots/design/components/button";
import {
  Dialog,
  DialogClose,
} from "@momots/design/components/dialog";

function SyncSettings() {
  const [open, setOpen] = useState(false);

  return (
    <Dialog
      open={open}
      onChange={setOpen}
      trigger={<Button>同步设置</Button>}
      title="确认同步设置"
      description="检查设置后再应用到当前工作区。"
      footer={
        <>
          <DialogClose render={<Button variant="secondary" />}>
            取消
          </DialogClose>
          <Button onClick={() => setOpen(false)}>应用设置</Button>
        </>
      }
    >
      本地修改会优先保留，并在发生冲突时生成恢复副本。
    </Dialog>
  );
}
```

`trigger` 会通过 Base UI 的 `Dialog.Trigger` 组合，因此会自动获得打开语义、键盘交互和 `aria` 属性。`DialogClose` 必须渲染在 `Dialog` 的正文或 `footer` 内；它适合为非受控 Dialog 提供“取消”等关闭操作。

## 非受控

不传 `open` 时，Dialog 会管理自己的状态：

```tsx
<Dialog
  defaultOpen={false}
  trigger={<Button>查看详情</Button>}
  title="同步详情"
  description="最近一次同步于 2 分钟前完成。"
>
  24 个条目已经同步，没有需要处理的冲突。
</Dialog>
```

`onChange` 是接受状态变化后的简化回调。需要读取关闭原因、阻止某次关闭或取得底层事件时，使用 `onOpenChange`：

```tsx
<Dialog
  title="编辑草稿"
  trigger={<Button>打开草稿</Button>}
  onOpenChange={(nextOpen, details) => {
    if (!nextOpen && details.reason === "outside-press" && hasUnsavedChanges) {
      details.cancel();
    }
  }}
>
  ...
</Dialog>
```

## 内容与焦点

- `title` 必填，并始终由 Base UI `Dialog.Title` 渲染，作为弹层的可访问名称。
- `description` 会由 `Dialog.Description` 渲染并自动关联到弹层。
- 正文区域会在内容超出可视高度时独立滚动，标题、关闭按钮和底部操作保持可见。
- 默认打开时聚焦首个可交互元素，关闭后焦点返回触发器。可通过 `popupProps.initialFocus` / `popupProps.finalFocus` 覆盖。
- `modal={true}` 或 `modal="trap-focus"` 时，弹层内应始终保留可见的关闭控件。若设置 `showCloseButton={false}`，请在正文或 `footer` 中渲染 `DialogClose`。
- `disablePointerDismissal` 只阻止点击弹层外部关闭；如需按关闭原因精细控制，请在 `onOpenChange` 中调用 `details.cancel()`。

不可逆的删除、支付等确认流程应使用 `AlertDialog` 语义，而不是把普通 Dialog 当作警报对话框。

## 内容节点

`title`、`description`、`children`、`footer` 使用共享的 [Content Slots](/docs/design/content-slots) 约定。通过 `slots` 配置标签、属性和样式：

```tsx
slots={{
  header: { render: <header /> },
  title: { render: <h3 />, className: "font-semibold" },
  content: { className: "space-y-3" },
  footer: { render: <footer /> },
}}
```

省略某个 slot 时使用默认节点，传 `false` 可隐藏节点。标题与说明的可访问关联由 Base UI 维护。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `open` | `boolean` | 受控打开状态 |
| `defaultOpen` | `boolean` | 非受控初始打开状态，默认 `false` |
| `onChange` | `(open: boolean) => void` | 状态变化未被取消后的简化回调 |
| `onOpenChange` | Base UI callback | 完整可取消回调，包含 `reason` 与底层事件 |
| `trigger` | `ReactElement` | 通过 `Dialog.Trigger` 组合的触发元素 |
| `title` | `ReactNode` | 必填的可访问标题 |
| `description` | `ReactNode` | 可选说明文字 |
| `children` | `ReactNode` | 可滚动的正文内容 |
| `footer` | `ReactNode` | 底部操作区域 |
| `size` | `"sm" \| "md" \| "lg"` | 弹层最大宽度，默认 `"md"` |
| `showCloseButton` | `boolean` | 是否显示右上角关闭按钮，默认 `true` |
| `closeLabel` | `string` | 内置关闭按钮的可访问名称 |
| `closeIcon` | `ReactNode` | 替换内置关闭图标 |
| `modal` | `boolean \| "trap-focus"` | 焦点圈定、页面滚动锁定与外部交互策略 |
| `disablePointerDismissal` | `boolean` | 阻止点击弹层外部关闭 |
| `triggerProps` / `portalProps` | Base UI props | 传给 Trigger 与 Portal 的底层属性 |
| `backdropProps` / `viewportProps` / `popupProps` | Base UI props | 传给遮罩、定位层与弹层的底层属性 |
| `closeProps` | Base UI props | 传给关闭节点的底层属性 |
| `className` | `string` | Popup 表面追加 Tailwind class |
| `triggerClassName` / `backdropClassName` / `viewportClassName` | `string` | 对应外层 slot 样式 |
| `slots` | `DialogProps['slots']` | 配置 header、title、description、content、footer 节点 |
| `closeClassName` | `string` | 关闭按钮样式 |

除上述属性外，其余 Base UI Dialog Root 属性会透传到内部 Root。
