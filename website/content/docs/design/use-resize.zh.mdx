`useResize` 在绑定元素后读取初始尺寸，并通过 `ResizeObserver` 监听后续尺寸变化。它适合图表容器、自定义布局和滚动区域；需要登记多个内容面板并输出动画尺寸时，使用 [useAutoSize](/docs/design/use-auto-size)。

## Playground

修改容器宽度，观察边框盒测量结果；开启“缩放为 75%”，测量值不会随视觉缩放改变。还可以暂停监听、切换布局或更换逻辑 key。

切换 `display` 时，演示会重新挂载被测节点，分别观察各布局的初次测量结果。

| 操作 | 观察结果 |
| --- | --- |
| `display: none` | 报告 `0 × 0`，表示有效的零尺寸 |
| `display: contents` | 报告 `null`，表示目标没有可测量的布局盒 |
| 暂停监听后修改宽度 | 保留最后一次报告，恢复后读取当前尺寸 |
| 更换逻辑 key | 即使尺寸相同，也重新报告一次初始尺寸 |

## 读取容器尺寸

用 callback ref 把节点保存到 state，再把节点传给 Hook：

```tsx
import { useState } from "react";
import type { ElementSize } from "@momots/design/hooks";
import { useResize } from "@momots/design/hooks";

function SizeProbe() {
  const [target, setTarget] = useState<HTMLDivElement | null>(null);
  const [size, setSize] = useState<ElementSize | null>(null);

  useResize(target, (_element, next) => setSize(next));

  return (
    <section>
      <div ref={setTarget} className="w-full border p-4">
        调整窗口宽度，观察这个容器的尺寸。
      </div>
      <output>
        {size === null
          ? "尚未测量或布局不受支持"
          : `${size.width.toFixed(1)} × ${size.height.toFixed(1)} CSS px`}
      </output>
    </section>
  );
}
```

不要仅在渲染时传入 `ref.current` 并期待它自动订阅。对象 ref 的赋值不会触发重渲染，而 callback ref 配合 state 可以让 Hook 收到初次挂载、替换和移除后的节点。

## 测量的是什么

**布局边框盒** 包括内容、内边距和边框，不包括外边距。返回的 `width` 和 `height` 是物理宽高，以 CSS 像素为单位，可能带小数；纵向书写模式也按物理轴返回。

CSS transform 不改变这里测量的布局尺寸。例如，`scale(2)` 使元素看起来放大，但不会让返回值翻倍。Hook 也不追踪元素的位置或只发生滚动的变化。

| 情况 | 行为 |
| --- | --- |
| `target === null` | 暂停监听，不调用回调，也不主动清空调用方已有尺寸 |
| 有效布局盒的宽高为零 | 返回 `{ width: 0, height: 0 }` |
| `display: none` | 返回有效的零尺寸 |
| `display: contents` 或普通非替换行内元素 | 回调收到 `null`，开发环境发出警告 |
| 不支持的布局变成有效布局盒 | 继续通过尺寸观察恢复测量 |

需要测量普通行内内容时，可增加 `inline-block`、`block`、`flex` 或 `grid` 包装。环境需要提供 `ResizeObserver`；Hook 不内置 polyfill。

## 回调与逻辑绑定

Hook 在 layout effect 中开始监听并读取初始尺寸，之后只在宽高或测量有效性变化时通知。更新 `onResize` 会使用最近一次提交的回调，不会仅因回调引用变化而重新订阅。

有些虚拟列表会复用同一个 DOM 节点显示不同条目。这时可以用 `key` 表达新的逻辑绑定：

```tsx
useResize(target, (_element, size) => {
  reportItemSize(itemId, size);
}, { key: itemId });
```

`key` 变化会重新订阅并报告初始尺寸，即使节点和尺寸没有变化。Hook 会忽略已清理监听器后续到达的通知；如果调用方另外安排了异步任务或队列更新，应用结果前仍需自行确认它属于当前条目。

不要让测量结果持续改变被测元素本身的尺寸，否则可能产生反馈循环。通常应测量内层内容，再更新外层容器或其他消费者。

## API

```ts
type ElementSize = Readonly<{ width: number; height: number }>;

type ResizeHandler<T extends HTMLElement> = (
  element: T,
  size: ElementSize | null,
) => void;

type ResizeOptions = { key?: unknown };

function useResize<T extends HTMLElement>(
  target: T | null,
  onResize: ResizeHandler<T>,
  options?: ResizeOptions,
): void;
```

Hook 不返回尺寸状态，由调用方选择如何使用回调结果。组件卸载、目标替换或 `key` 变化时，会断开旧的观察器。
