`@momots/design` 使用三层 token：

| 层级 | 前缀 | 说明 |
| --- | --- | --- |
| Primitive | 无 `momo` 前缀 | 默认使用 Tailwind 色盘；主题独有色值用类 Tailwind 命名写在主题 CSS 的 `@theme` 中 |
| Semantic | `--momo-bg-*`、`--momo-fg-*`、`--momo-border-*`、`--momo-ring-*` | 组件直接消费的语义层，跨主题命名一致 |
| Base | `--momo-font-*`、`--momo-radius-*`、`--momo-space-*`、`--momo-shadow-*`、`--momo-text-*` | 字体、圆角、间距、阴影、字号阶梯 |

当前内置两套主题：

- `neutral`：shadcn `neutral` 主题，取值来自 `shadcn@4.13.0` 的官方 registry。
- `anthropic`：基于 `packages/design/DESIGN.md` 的 Claude / Anthropic 暖调主题。

组件不再消费 `--momo-primary`、`--momo-background` 这类旧 alias；颜色统一用 `bg-*` 和 `fg-*` 区分背景与文本。

## 引入方式

```css
@import "tailwindcss";
@import "@momots/design/themes/neutral.css";
@import "@momots/design/themes/anthropic.css";
```

推荐把 momo theme class 挂在应用根节点，也就是 `html` / `:root`。这样默认 portal 到 `body` 的浮层组件（例如 Select、Popover、Menu）也能继承同一份 `--momo-*` token：

```tsx
<html className="theme-neutral">
  <body>
    <App />
  </body>
</html>

<html className="theme-neutral dark">
  <body>
    <App />
  </body>
</html>
```

如果应用支持主题切换，只需要替换 `html` 上的主题 class：

| Class | 说明 |
| --- | --- |
| `theme-neutral` | Neutral 亮色 |
| `theme-neutral dark` | Neutral 暗色 |
| `theme-anthropic` | Anthropic 亮色 |
| `theme-anthropic dark` | Anthropic 暗色 |

也可以把 `dark` 放在祖先节点上：`.dark .theme-neutral` 和 `.dark .theme-anthropic` 都会生效。

局部容器也可以挂载主题 class，但它只适合无 portal 的隔离预览或嵌入场景。对于默认挂载到 `body` 的浮层，局部容器内的 token 不会自动传递到 portal；此时应优先把主题挂到 `html`，或者由应用显式传入组件的 portal container。

组件不会自动引入主题文件；应用侧必须显式引入需要的主题 CSS。

## Base Tokens

### Typography

| Token | Utility | 语义 |
| --- | --- | --- |
| `--momo-font-display` | `font-momo-display` | 展示型标题字体 |
| `--momo-font-body` | `font-momo-body` | UI 与正文文字 |
| `--momo-font-mono` | `font-momo-mono` | 代码 / 等宽字体 |

每档字号都有 `-leading`、`-tracking`、`-weight` 伴生变量，并通过 `@theme inline` 注册为 Tailwind `text-momo-*` utility：

| Utility | 语义 |
| --- | --- |
| `text-momo-display-xl` / `-lg` / `-md` / `-sm` | 展示型标题 |
| `text-momo-title-lg` / `-md` / `-sm` | 卡片标题、列表标题 |
| `text-momo-body-md` / `-sm` | 正文与辅助说明 |
| `text-momo-caption` / `text-momo-caption-uppercase` | 徽章、小字注释、分类标签 |
| `text-momo-code` | 代码文字 |
| `text-momo-button` | 按钮文字 |
| `text-momo-nav-link` | 导航链接 |

### Shape, Spacing, Shadow

| Token | Utility | 语义 |
| --- | --- | --- |
| `--momo-radius-xs` ~ `--momo-radius-full` | `rounded-momo-xs` ~ `rounded-momo-full` | 圆角阶梯 |
| `--momo-space-xxs` ~ `--momo-space-section` | `p-momo-md`、`gap-momo-lg` 等 | 间距阶梯 |
| `--momo-shadow-sm` | `shadow-momo-sm` | 低强度层级阴影 |

## 示例

```tsx
<button className="rounded-momo-md bg-momo-bg-brand px-momo-md text-momo-button text-momo-fg-on-brand hover:bg-momo-bg-brand-hover">
  Continue
</button>
```

```tsx
<div className="rounded-momo-lg border border-momo-border-default bg-momo-bg-surface-raised p-momo-lg text-momo-fg-default">
  <p className="text-momo-body-sm text-momo-fg-muted">Semantic tokens stay stable across themes.</p>
</div>
```

## 新增主题

1. 复制 `packages/design/src/themes/neutral.css` 或 `anthropic.css`。
2. 主题私有 primitive 使用 Tailwind 原生命名或类 Tailwind 命名，不加 `--momo` 前缀。
3. 补齐完全相同的 semantic / base token 名称。
4. 引入 `./semantic.css`，让 `bg-momo-bg-*`、`text-momo-fg-*`、`border-momo-border-*` 等 utility 可用。
5. 不添加 CSS animation token；组件动画默认交给 Motion。
