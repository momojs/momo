`Drawer` wraps Base UI Drawer with focus management, swipe dismissal, four directions, and vertical snap points. Compose headings, descriptions, triggers, body, and footer actions through slots.

<DrawerPlayground />

## Usage

```tsx
import { Button } from "@momots/design/components/button";
import {
  Drawer,
  DrawerClose,
} from "@momots/design/components/drawer";

<Drawer
  direction="down"
  trigger={<Button>Notification settings</Button>}
  title="Notification settings"
  description="Choose how the workspace receives notifications."
  slots={{ content: { className: "min-h-0" } }}
  footer={
    <div className="w-full p-4 pt-2">
      <DrawerClose render={<Button className="w-full" />}>
        Done
      </DrawerClose>
    </div>
  }
>
  <div className="min-h-0 flex-1 overflow-y-auto p-4">
    Drawer body
  </div>
</Drawer>
```

Always provide `title` for the drawer's accessible name. Both `title` and `description` accept ReactNode content; configure node rendering through `slots.title.render` and `slots.description.render`. `DrawerClose` must be inside its Drawer.

## Swiping and snap points

```tsx
const points = [0.35, 0.7, 1];

<Drawer
  direction="down"
  snapPoints={points}
  defaultSnapPoint={0.7}
  snapToSequentialPoints
>
  ...
</Drawer>
```

Snap points apply only to `up` and `down`. Numbers at most `1` are viewport-height fractions; larger numbers are pixels. `px` and `rem` strings are also accepted. Combine `snapPoint` with `onSnapPointChange` for controlled snapping.

`swipe` only controls visibility of the built-in drag handle and defaults to `true`; Base UI swipe gestures remain managed by Drawer Root. `direction` determines both opening and dismissal gesture direction.

## Modal

- `modal={true}` traps focus, locks scrolling, blocks outside pointer interaction, and displays a backdrop.
- `modal={false}` allows interaction with the rest of the page and shows no backdrop.
- `modal="trap-focus"` only traps focus, without locking scrolling or blocking outside pointer interaction.

Modal Drawers should have a title and visible `DrawerClose`. Use `disablePointerDismissal` to prevent outside-click dismissal, or `onOpenChange` details to inspect/cancel dismissal reasons.

## Slots

Drawer follows [Content Slots](/docs/design/content-slots): `title`, `description`, `children`, and `footer` supply content; `slots.header`, `slots.title`, `slots.description`, `slots.content`, and `slots.footer` configure nodes.

```tsx
<Drawer
  title="Notification settings"
  slots={{
    header: { render: <header /> },
    title: { render: <h3 /> },
    content: { className: "gap-3" },
    footer: { className: "p-4" },
  }}
  footer={<DrawerClose render={<Button />}>Done</DrawerClose>}
>
  Drawer body
</Drawer>
```

`slots.content` configures only the body, excluding the handle, heading, and footer. The internal Base UI Content container handles swiping and nesting, unaffected by body-slot replacement or hiding. `trigger` still accepts a Base UI render element or callback.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `open` | `boolean` | Controlled open state |
| `defaultOpen` | `boolean` | Uncontrolled initial state; defaults to `false` |
| `onOpenChange` | Base UI callback | State change callback; details include dismissal reason and cancellation |
| `onOpenChangeComplete` | `(open: boolean) => void` | Called after opening or closing animation completes |
| `direction` | `"up" \| "down" \| "left" \| "right"` | Opening and swipe-dismissal direction; defaults to `"down"` |
| `swipe` | `boolean` | Shows the built-in drag handle; defaults to `true` |
| `modal` | `boolean \| "trap-focus"` | Focus, scroll-locking, and outside interaction policy; defaults to `true` |
| `disablePointerDismissal` | `boolean` | Prevents outside-click dismissal |
| `snapPoints` | `(number \| string)[]` | Snap points for vertical Drawers |
| `snapPoint` / `defaultSnapPoint` | `number \| string \| null` | Controlled or uncontrolled snap point |
| `onSnapPointChange` | Base UI callback | Snap-point change callback |
| `snapToSequentialPoints` | `boolean` | Restricts movement to adjacent snap points |
| `children` | `ReactNode` | Drawer body |

Other Base UI Drawer Root props are forwarded to the internal Root.
