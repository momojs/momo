`Select` 使用 Base UI Select 提供键盘导航、表单提交与无障碍语义。组件默认渲染 Base UI 推荐的 `Trigger`、`Value`、`Icon`、`Portal`、`Positioner`、`Popup`、`List`、`ScrollArrow`、`Item`、`ItemIndicator` 与 `ItemText` 结构，并通过 momo semantic token 适配当前主题。

## 使用

```tsx
import { Select } from "@momots/design/components/select";

<Select
  value={fruit}
  onChange={setFruit}
  placeholder="Select a fruit..."
  options={[
    { value: "apple", label: "Apple" },
    { value: "banana", label: "Banana" },
    { value: "cherry", label: "Cherry" },
  ]}
/>;
```

## 受控打开

```tsx
<Select
  open={open}
  onOpenChange={setOpen}
  value={fruit}
  onValueChange={(next) => {
    if (next) setFruit(next);
  }}
  options={options}
/>
```

`onChange` 是 momo 的简化回调，只在非空选项值变化时触发；需要完整 Base UI 事件信息或处理 `null` 值时，使用 `onValueChange`。
`open` 通过 momo 的 `useControllableValue` 处理；`value` / `defaultValue` 交由 Base UI 管理选中状态。

## 选项布局

选项与 Menu 使用相同的列顺序：`[图标或占位] [标题] [可选辅助信息] [指示器]`。`options[].icon` 显示在逻辑起点，`options[].extra` 显示在标题与指示器之间。两端的图标和指示器列始终保留固定宽度，因此没有图标、切换选中状态或设置 `itemIndicator={false}` 都不会改变标题起点。选中状态由末端勾选表达，不改变文字字重。

```tsx
<Select
  options={[
    { value: 'personal', label: '个人空间', extra: '免费' },
    { value: 'team', label: '团队空间', icon: <TeamIcon />, extra: '专业版' },
  ]}
/>
```

标题与过长的辅助信息会省略显示；辅助信息最多占一行可用宽度的 40%。`extra` 保留可访问文本，装饰图标与勾选对辅助技术隐藏，选中状态通过 Base UI 的 `aria-selected` 表达。选中的触发器文本仍取自 `label`，不包含 `extra`。

RTL 场景使用 Base UI 的 `DirectionProvider direction='rtl'` 并为应用容器设置 `dir='rtl'`；Portal 浮层会继承 provider 的方向，图标与勾选按照 start / end 镜像排列。

## 自定义弹层

```tsx
<Select
  options={options}
  positioner={{
    alignItemWithTrigger: false,
    sideOffset: 8,
  }}
  popup={{ className: "min-w-64" }}
  list={{ className: "p-1" }}
/>
```

所有 slot 默认开启。传入 props object 会配置默认的 Base UI primitive，并保留其交互、状态参数和可访问语义；传入 `false` 可移除 slot，传入 ReactNode 则会完整替换它。Trigger、Popup、Item 等结构性 slot 通常应优先使用 props object，自定义底层元素时使用对应 Base UI `render` prop。

可配置的 slot 包括 `trigger`、`valueSlot`、`icon`、`portal`、`positioner`、`popup`、`list`、`item`、`itemText`、`itemIndicator`、`scrollUpArrow` 与 `scrollDownArrow`。`valueSlot` 特意与表示当前选中值的 `value` 分开命名。

默认 Popup 保留 Motion 的进入 / 退出动画，并通过 `MotionConfig` 遵循用户的 reduced-motion 设置。只有这条默认动画路径会由 `Select` 在退出完成后调用 `unmount`；移除结构 slot 或覆盖 `popup.render` 时，卸载生命周期交回 Base UI（显式传入 `actionsRef` 时则由调用方管理）。

更多 Base UI 行为通过 `Select` 的 root props 与 slot config 透传，不额外暴露底层 primitive。`Select` 不会自动改写 Portal 挂载点；应用应把 momo theme class 挂在 `html` / `:root` 上，让默认挂载到 `body` 的 popup 也能继承 `--momo-*` token。需要自定义挂载点时使用 `portal={{ container }}`。

选项 hover 背景由 `useHighlightLayer`、`useHighlightTrigger` 与 `Highlight` 驱动。`highlightItemOnHover` 默认 `true`，同时启用 Base UI 的 pointer highlight 状态和 momo 的 motion highlight；设置为 `false` 时仍保留键盘导航。

## 多选

```tsx
const [fruits, setFruits] = useState<Fruit[]>(["apple", "cherry"]);

<Select<Fruit, true>
  multiple
  value={fruits}
  onChange={setFruits}
  options={options}
/>
```

`multiple={true}` 时，`value`、`defaultValue` 与 `onChange` 的值都是 `T[]`；单选模式的 `value` / `defaultValue` 可以是 `T` 或 `null`。`onChange` 只跳过单选清空时的 `null`；多选清空产生的空数组 `[]` 仍会触发回调。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `value` | `T \| null`；多选为 `T[]` | 当前选中值 |
| `defaultValue` | `T \| null`；多选为 `T[]` | 非受控默认值 |
| `options` | `ControlOption<T>[]` | 简化选项列表，支持 `label`、`icon`、`extra`、`disabled`、`className`、`style`、`textValue` |
| `items` | Base UI Root `items` | 传给内部 Root 的 value-label 映射；默认使用 `options` |
| `children` | `ReactNode` | 自定义 `List` 内部内容，适合分组或自定义 item |
| `size` | `"sm" \| "md" \| "lg"` | 控件尺寸 |
| `placeholder` | `ReactNode` | 未选中时的占位文案 |
| `disabled` | `boolean` | 是否禁用 |
| `readOnly` | `boolean` | 是否只读 |
| `multiple` | `boolean` | 是否允许多选 |
| `highlightItemOnHover` | `boolean` | 是否启用 pointer hover highlight，默认 `true` |
| `open` / `defaultOpen` | `boolean` | 受控 / 非受控弹层打开状态 |
| `name` | `string` | 表单字段名 |
| `form` | `string` | 关联外部表单 |
| `autoComplete` | `string` | 浏览器自动填充提示 |
| `required` | `boolean` | 是否必填 |
| `modal` | `boolean` | 打开时是否进入 modal 交互模式 |
| `actionsRef` | Base UI actions ref | 传给内部 Root 的 imperative actions；内置 Motion 退出完成后会通过它执行 `unmount` |
| `trigger` | slot config | Trigger 配置，默认开启 |
| `valueSlot` | slot config | Value 配置，默认开启 |
| `icon` | slot config | Icon 配置，默认开启 |
| `portal` | slot config | Portal 配置，默认开启 |
| `positioner` | slot config | Positioner 配置，默认开启 |
| `popup` | slot config | Popup 配置，默认开启 |
| `list` | slot config | List 配置，默认开启 |
| `item` | slot config | 自动生成的每个 Item 的公共配置，默认开启 |
| `itemText` / `itemIndicator` | slot config | ItemText / ItemIndicator 配置，默认开启 |
| `scrollUpArrow` / `scrollDownArrow` | slot config | 上下滚动箭头配置，默认开启 |
| `indicator` | `ReactNode` | 自定义选中图标 |
| `onChange` | `(value: T) => void`；多选为 `(value: T[]) => void` | 简化选中项变化回调，不包含 `null` |
| `onValueChange` | Base UI callback | 完整值变化回调，包含 event details |
| `onOpenChange` | Base UI callback | 弹层打开状态变化回调 |
