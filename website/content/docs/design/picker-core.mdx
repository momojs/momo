`PickerCore` underlies `PickerDate` and `PickerTime`. It renders groups of `ControlOption` as adjacent wheels for party sizes, time periods, or other compound values.

## Usage

```tsx
import { useState } from "react";

import { PickerCore } from "@momots/design/components/picker-core";

const columns = [
  [
    { value: "1", label: "1 person" },
    { value: "2", label: "2 people" },
    { value: "8+", label: "8 or more", disabled: true },
  ],
  Array.from({ length: 12 }, (_, index) => ({
    value: String(index + 1),
    label: String(index + 1),
  })),
  [
    { value: "am", label: "AM" },
    { value: "pm", label: "PM" },
  ],
];

function ReservationPicker() {
  const [value, setValue] = useState(["2", "7", "pm"]);

  return (
    <PickerCore<string>
      aria-label="Appointment time"
      columnAriaLabels={["People", "Hour", "Period"]}
      columns={columns}
      value={value}
      infinite={[false, true, false]}
      onChange={setValue}
    />
  );
}
```

Indices in `value` correspond to `columns`. All columns share one generic value type, currently `string` or `number`. Controlled values should always refer to existing, enabled options in every column; the component does not normalize invalid values.

## Accessibility

- Name the whole picker through `aria-label` or `aria-labelledby`.
- Give each column a specific `columnAriaLabels` name; otherwise generic names such as `Column 1` are used.
- Supply `textValue` when an option `label` is non-text ReactNode.
- `disabled` adds disabled semantics to the group and columns and prevents focus/pointer interaction.

Each column uses vertical `listbox` semantics, associating its current option through `aria-activedescendant`. `infinite` may be one boolean for all columns or an indexed boolean array.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `columns` | `ControlOption<T>[][]` | Options grouped by column |
| `value` | `T[]` | Controlled values indexed by column |
| `onChange` | `(value: T[]) => void` | Called when any column changes |
| `disabled` | `boolean` | Disables every wheel |
| `infinite` | `boolean \| boolean[]` | Global or per-column infinite scrolling |
| `aria-label` / `aria-labelledby` | `string` | Accessible name for the whole picker |
| `columnAriaLabels` | `readonly string[]` | Accessible names for each wheel |
| `visibleCount` | `number` | Visible item count in the circular list; must be a multiple of `4` |
| `dragSensitivity` | `number` | Drag sensitivity |
| `scrollSensitivity` | `number` | Wheel-scroll sensitivity |
| `optionItemHeight` | `number` | Item height in pixels |
| `className` | `string` | Additional WheelPickerWrapper classes |
| `columnClassName` | `string` | Additional classes on each wheel root |
