`PickerCore` 是 `PickerDate` 与 `PickerTime` 的基础组件。它将多组 `ControlOption` 渲染为并排滚轮，适合人数、时段或其他自定义组合值。

## 使用

```tsx
import { useState } from "react";

import { PickerCore } from "@momots/design/components/picker-core";

const columns = [
  [
    { value: "1", label: "1 人" },
    { value: "2", label: "2 人" },
    { value: "8+", label: "8 人以上", disabled: true },
  ],
  Array.from({ length: 12 }, (_, index) => ({
    value: String(index + 1),
    label: String(index + 1),
  })),
  [
    { value: "am", label: "上午" },
    { value: "pm", label: "下午" },
  ],
];

function ReservationPicker() {
  const [value, setValue] = useState(["2", "7", "pm"]);

  return (
    <PickerCore<string>
      aria-label="预约时间"
      columnAriaLabels={["人数", "小时", "时段"]}
      columns={columns}
      value={value}
      infinite={[false, true, false]}
      onChange={setValue}
    />
  );
}
```

`value` 中的索引与 `columns` 一一对应。所有列共用同一个泛型值类型，当前支持 `string` 或 `number`。受控值应始终包含每一列中存在且未禁用的 option；组件不会替调用方规范化无效值。

## 可访问性

- 使用 `aria-label` 或 `aria-labelledby` 为整个选择器命名。
- 使用 `columnAriaLabels` 为每一列提供具体名称；未传入时会退回到 `Column 1` 等通用名称。
- option 的 `label` 为非文本 ReactNode 时，应提供 `textValue`。
- `disabled` 会为组合与各列设置禁用语义，并阻止焦点及指针交互。

每一列使用纵向 `listbox` 语义，当前 option 通过 `aria-activedescendant` 关联。`infinite` 可以是作用于所有列的 boolean，也可以是与列索引对应的 boolean 数组。

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `columns` | `ControlOption<T>[][]` | 按列排列的选项 |
| `value` | `T[]` | 受控值，索引与列对应 |
| `onChange` | `(value: T[]) => void` | 任一列变化后的回调 |
| `disabled` | `boolean` | 是否禁用全部滚轮 |
| `infinite` | `boolean \| boolean[]` | 全局或逐列循环滚动 |
| `aria-label` / `aria-labelledby` | `string` | 整个选择器的可访问名称 |
| `columnAriaLabels` | `readonly string[]` | 各滚轮的可访问名称 |
| `visibleCount` | `number` | 环形列表的可见项数，必须是 `4` 的倍数 |
| `dragSensitivity` | `number` | 拖动灵敏度 |
| `scrollSensitivity` | `number` | 滚轮滚动灵敏度 |
| `optionItemHeight` | `number` | 单项像素高度 |
| `className` | `string` | WheelPickerWrapper 追加 class |
| `columnClassName` | `string` | 为每个滚轮根节点追加的 class |
