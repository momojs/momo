`useMergedRefs` combines refs into one stable callback ref so the component and caller receive the same node. Use it for internal measurement, focus, or third-party binding while exposing the node externally.

The object ref handles focusing and the callback ref observes focus events; both bind through one merged ref. Clearing event history resets only demo logs without rebinding refs.

## Internal and external refs

This input uses an internal ref for focus while preserving the caller's ref:

```tsx
import type { ComponentPropsWithRef } from "react";
import { useRef } from "react";
import { useMergedRefs } from "@momots/design/hooks";

function SearchInput({
  ref,
  ...props
}: ComponentPropsWithRef<"input">) {
  const inputRef = useRef<HTMLInputElement>(null);
  const mergedRef = useMergedRefs(inputRef, ref);

  return (
    <div>
      <input {...props} ref={mergedRef} />
      <button type="button" onClick={() => inputRef.current?.focus()}>
        Focus input
      </button>
    </div>
  );
}

function Search() {
  const ref = useRef<HTMLInputElement>(null);
  return <SearchInput ref={ref} aria-label="Search projects" />;
}
```

You can also import from `@momots/design/hooks/use-merged-refs`. The example uses React 19's ref prop without a `forwardRef` wrapper.

## Mounting and cleanup

A **callback ref** receives a node and may return a cleanup function to release resources when detached.

| Input ref | On attachment | On detachment |
| --- | --- | --- |
| Object ref | Writes the node to `.current` | Sets `.current` to `null` |
| Callback returning cleanup | Calls the callback and stores cleanup | Calls cleanup without an additional `ref(null)` |
| Callback without cleanup | Calls `ref(node)` | Calls `ref(null)` |
| `null` / `undefined` | Ignored | Ignored |

For example, a callback ref can own native event-listener lifecycle:

```tsx
import { useCallback, useRef } from "react";
import { useMergedRefs } from "@momots/design/hooks";

function FocusProbe() {
  const localRef = useRef<HTMLInputElement>(null);
  const observe = useCallback((node: HTMLInputElement | null) => {
    if (!node) return;
    const onFocus = () => console.log("Input focused");
    node.addEventListener("focus", onFocus);
    return () => node.removeEventListener("focus", onFocus);
  }, []);
  const ref = useMergedRefs(localRef, observe);

  return <input ref={ref} aria-label="Focus example" />;
}
```

## When input refs change

The merged callback stays stable for one component mount. When input ref count, order, or references change, the hook cleans up the old group at commit and binds the current node to the new group, even if the DOM node is unchanged.

A stable merged callback therefore does not mean input callbacks run only once. Inline callback refs change each render, triggering cleanup and rebinding; use `useCallback` to avoid unnecessary work. Development StrictMode may also perform additional binding and cleanup.

## API

```ts
function useMergedRefs<Value>(
  ...refs: Array<React.Ref<Value> | undefined>
): React.RefCallback<Value>;
```

All input refs should target the same value type. Bind one merged ref to only one node. For multiple nodes, call the hook separately or use a dedicated node registry.
