Highlight separates DOM measurement, target registration, interaction events, and Motion rendering into four composable APIs. It suits tabs, segmented controls, menu hover, and moving selection backgrounds.

<HighlightPlayground />

## Imports

Import `Highlight` from its component subpath, and measurement, registration, and interaction hooks from `hooks`:

```tsx
import { Highlight } from "@momots/design/components/highlight";
import {
  useHighlightLayer,
  useHighlightRegistrar,
  useHighlightTrigger,
} from "@momots/design/hooks";
```

## How it works

1. `useHighlightLayer` measures targets relative to their container and produces Motion styles, automatically remeasuring when target or container dimensions change.
2. `useHighlightTrigger` connects hover, click, or focus events to a layer.
3. `useHighlightRegistrar` registers elements by stable values for controlled selection.
4. `Highlight` renders and animates the absolutely positioned layer using its styles.

The container must establish a positioning context, usually `position: relative`. Interactive content must sit above the highlight. `Highlight` uses `pointer-events: none` and does not intercept clicks.

## Moving highlights

This example uses both a hover layer and a selected layer:

```tsx
function Navigation() {
  const [value, setValue] = useState("overview");
  const containerRef = useRef<HTMLDivElement>(null);

  const hoverLayer = useHighlightLayer<HTMLButtonElement, HTMLDivElement>(
    containerRef,
  );
  const selectedLayer = useHighlightLayer<HTMLButtonElement, HTMLDivElement>(
    containerRef,
  );
  const hover = useHighlightTrigger(hoverLayer, { trigger: "hover" });
  const selected = useHighlightRegistrar(selectedLayer);

  useLayoutEffect(() => {
    selected.activate(value);
  }, [selected.activate, value]);

  return (
    <div ref={containerRef} className="relative flex gap-1">
      <Highlight
        className="bg-momo-bg-surface-muted"
        highlightStyle={hoverLayer.style}
      />
      <Highlight
        className="bg-momo-bg-brand"
        highlightStyle={
          selectedLayer.style
            ? { ...selectedLayer.style, zIndex: 1 }
            : null
        }
      />

      {items.map((item) => (
        <button
          key={item.value}
          ref={selected.register(item.value)}
          className="relative z-9"
          {...hover.getReferenceProps({
            onClick: () => setValue(item.value),
          })}
        >
          {item.label}
        </button>
      ))}
    </div>
  );
}
```

When sharing a container between layers, override `zIndex` in `highlightStyle` to define hover and selection stacking.

## useHighlightLayer

```ts
const layer = useHighlightLayer(targetContainerRef, { enabled: true });
```

Return value:

| Field | Description |
| --- | --- |
| `style` | Target `x`, `y`, `width`, `height`, and `zIndex` relative to the container; `null` without a target |
| `setTarget(element)` | Measures and activates a target; observes target/container resize while `enabled` |
| `clear(target?)` | Clears the layer and stops observation; a non-current target cannot accidentally clear a new target |
| `flush()` | Remeasures the current target; call manually for changes resize cannot detect, such as container scrolling |

Measurement accounts for container borders and scroll offsets. Active layers observe target and container dimensions through Motion `resize` and automatically `flush()`. Internal scrolling does not currently trigger remeasurement; call `flush()` on scroll when the highlight must follow it.

Setting `enabled` to `false` clears styles and stops observation but retains the target. Re-enabling remeasures and resumes observation. Unmounting completely cleans up the target and subscriptions.

## useHighlightRegistrar

The registrar maps stable application values to DOM elements through `ControlValue`:

```tsx
const registrar = useHighlightRegistrar(layer);

<button ref={registrar.register("account")} />
registrar.activate("account");
registrar.clear();
```

| Field | Description |
| --- | --- |
| `register(value)` | Returns a cached callback ref handling mount, unmount, and target cleanup |
| `activate(value)` | Activates a registered element, continuing to match that value if it mounts later |
| `clear()` | Clears the current value and layer |

Values must be unique within a registrar; later registration otherwise replaces the same mapping.

## useHighlightTrigger

```ts
const trigger = useHighlightTrigger(layer, {
  enabled: true,
  trigger: "hover", // "hover" | "click" | "focus"
});
```

`getReferenceProps(existingProps?)` returns event props to spread on the target, calling supplied handlers first:

| Mode | Behavior |
| --- | --- |
| `hover` | Activates on pointer enter, clears on pointer leave; automatically disabled on mobile |
| `click` | Activates on click without automatically clearing |
| `focus` | Activates on focus, clears on blur |

When the trigger is disabled, `getReferenceProps` returns existing props unchanged. Changing mode does not clear the previous mode's target; call `layer.clear()` alongside dynamic mode changes if needed.

## Highlight

| Prop | Type | Description |
| --- | --- | --- |
| `highlightStyle` | `StyleKeyframesDefinition \| null` | Usually `layer.style`, controlling position and dimensions |
| `active` | `boolean` | Keeps the layer visible without measured styles, useful for container-filling highlights |
| `exitDelay` | `number` | Exit delay in milliseconds |
| `transition` | Motion `Transition` | Currently merged only into the exit transition |
| `className` | `string` | Highlight color, radius, shadow, and other visual styles |
| `...props` | `ComponentProps<typeof motion.div>` | Other Motion div props |

When `active` is false and `highlightStyle` is `null`, `AnimatePresence` runs the exit. Scale and opacity animate appearance/disappearance while Motion interpolates position and dimensions between targets. `exitDelay` and `transition.delay` affect only exit; the `transition` prop is not currently passed to entry or movement states.
