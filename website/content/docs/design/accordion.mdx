`Accordion` uses Base UI Accordion for disclosure semantics and Motion for expanded height and focus feedback. Arrows transition between up/down shapes through [Icon](/docs/design/icon). Styles consume `--momo-bg-*`, `--momo-fg-*`, `--momo-border-*`, and `--momo-ring-*` semantic tokens.

<AccordionPlayground />

## Usage

```tsx
import { Accordion } from "@momots/design/components/accordion";

<Accordion
  value={openItems}
  onValueChange={setOpenItems}
  options={[
    {
      value: "tokens",
      label: "Semantic tokens",
      content: "Accordion follows the active momo theme.",
    },
    {
      value: "motion",
      label: "Motion first",
      content: "Height and focus feedback are animated with motion.",
    },
  ]}
/>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `T \| T[]` | Expanded item; use an array when `multiple` is `true` |
| `defaultValue` | `T \| T[]` | Uncontrolled initial expanded item; use an array when `multiple` is `true` |
| `options` | `AccordionOption<T>[]` | Panel list; simplified rendering currently consumes `value`, `label`, and `content` |
| `multiple` | `boolean` | Allows multiple expanded panels |
| `className` | `string` | Additional Tailwind classes on the root |
| `onValueChange` | Base UI callback | Expanded-item change callback; value shape follows `multiple` |
