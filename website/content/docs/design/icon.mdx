`Icon` accepts icon data, renders its target immediately on first mount, then morphs subsequent `icon` changes through Morphicons. Dimensions, color, and stroke use ordinary SVG props; animation reads momo's `snap` configuration without requiring a Provider.

## Usage

```tsx
import { CheckmarkCircle02Icon, Copy01Icon } from "@hugeicons/core-free-icons";
import { Icon } from "@momots/design/components/icon";

<Icon icon={copied ? CheckmarkCircle02Icon : Copy01Icon} />;
```

Morphicons is an ordinary `@momots/design` dependency installed with the library. Existing Hugeicons projects can retain `@hugeicons/core-free-icons` data imports and replace suitable `HugeiconsIcon` usages with `Icon`. Do not key React elements by the current icon; remounting prevents continuity from the previous shape.

`Icon` is also exported from `@momots/design` and `@momots/design/components`; related types are `IconProps` and `IconData`.

## Icon data

`icon` accepts a raw SVG path `d` string or `[tag, attrs][]` node data. Hugeicons outline data works directly. Other icon libraries must provide data rather than React components or `<svg>` elements.

```tsx
import type { IconData } from "@momots/design/components/icon";

const menu = [
  ["path", { d: "M4 6h16M4 12h16M4 18h16" }],
] as const satisfies IconData;

<Icon icon={menu} size={24} />;
```

Supported data includes `path`, `line`, `circle`, `ellipse`, `rect`, `polyline`, and `polygon`. Both endpoints must share a coordinate space, defaulting to `24 × 24`. Define custom data at module scope or keep references stable to avoid new data objects each render.

This entry targets monochrome outline icons with uniform strokes. It combines geometry into one path, discarding per-node colors, stroke widths, and opacity. Icons depending on `g`, `transform`, masks, gradients, or filled shapes are unsupported; use their original components or custom slots. `morph={false}` disables transitions without expanding supported data.

## Motion and loading

`Icon` uses `snap` spring parameters from `MotionUIThemeProvider`, falling back to momo's default theme. Rapid changes continue from the current shape toward the new target.

With system reduced motion, both `calm` and `off` switch shapes immediately and stop active morphing. Transitions can also be disabled per icon:

```tsx
<Icon icon={currentIcon} morph={false} />;
```

Use `Spinner` for loading; `Icon` has no `spin`. To smoothly transition from loading to a result, retain the same `Spinner` and pass the target through `icon`:

```tsx
import { CheckmarkCircle02Icon } from "@hugeicons/core-free-icons";
import { Spinner } from "@momots/design/components/spinner";

<Spinner
  icon={loading ? undefined : CheckmarkCircle02Icon}
  aria-hidden
/>;
```

Without `icon`, the original arc expansion and rotation play. Providing it morphs the currently visible arc, including its rotation, into the target. Further icon changes keep morphing. Removing `icon` stops current morphing and immediately starts a new loading cycle.

The arc is completely invisible briefly at the end of each loop. If loading finishes then, the result icon fades in to avoid an unexplained full-ring flash.

`Spinner` and `Icon` share morphing logic and the `snap` theme. Default stroke width is `1.8`, customizable through `strokeWidth`. Spinner dimensions retain `width` / `height`, defaulting to `1em`. `morph={false}` disables shape transitions; system reduced motion also stops loading loops. Replacing `<Spinner />` with `<Icon />` still does not connect their animations.

## Accessibility and refs

Decorative icons in buttons default to `aria-hidden`; the button supplies the accessible name:

```tsx
<button type="button" aria-label="Copy" onClick={copy}>
  <Icon icon={Copy01Icon} />
</button>
```

For standalone meaning, provide `label` to generate `<title>` and `role="img"`. Native `aria-label` and `aria-labelledby` are also supported. `ref` points to the actual `SVGSVGElement`.

```tsx
<Icon icon={CheckmarkCircle02Icon} label="Saved successfully" />;
```

## Props

| Prop | Type | Default | Purpose |
| --- | --- | --- | --- |
| `icon` | `IconData` | Required | Current outline-icon data or path string |
| `morph` | `boolean` | `true` | Animates subsequent icon changes |
| `size` | `number \| string` | `18` | SVG width/height; supports pixels or `"1em"` |
| `strokeWidth` | `number \| string` | `1.8` | Uniform stroke width |
| `color` | `string` | `"currentColor"` | Stroke color, following text color by default |
| `label` | `string` | — | Accessible name for a standalone icon |
| Other | SVG props | — | `className`, events, ARIA, and native SVG ref |
