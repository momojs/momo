`Button` builds on `motion.button`, with variants and sizes, subtle press scaling, and momo semantic styles.

<ButtonPlayground />

## Usage

```tsx
import { Button } from "@momots/design/components/button";

<Button variant="default" size="default" onClick={() => console.log("clicked")}>
  Continue
</Button>
```

## Event semantics

`onTap` follows Motion tap gestures directly: completed pointer/touch taps and Enter on a focused button. Canceled gestures do not call `onTap`. Native Space-generated clicks and `HTMLElement.click()` are not converted into taps.

`onClick` handles native clicks. Use it when responding to native button activation.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `variant` | `"default" \| "accent" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | Visual variant |
| `size` | `"default" \| "inline" \| "xs" \| "sm" \| "lg" \| "xl" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | Size; `inline` uses `inline-flex` with width and height `unset` |
| `className` | `string` | Additional Tailwind classes |
| `disabled` | `boolean` | Disables the button |
| `...props` | `HTMLMotionProps<"button">` | Other native button / Motion props |
