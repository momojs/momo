`Switch` 使用 Base UI Switch 提供隐藏 input、受控/非受控状态和表单提交语义。组件只渲染开关本体，标签与说明文字由调用方组合；thumb 内容可通过 `checkedIcon` / `uncheckedIcon` 自定义。轨道、thumb 内容与 focus ring 消费 momo semantic token。

<SwitchPlayground />

## 使用

```tsx
import { Switch } from "@momots/design/components/switch";

<Switch
  checked={enabled}
  size="md"
  aria-label="Notifications"
  onCheckedChange={setEnabled}
/>
```

需要 label 时，把 `Switch` 放进外部 `label` 或相邻布局中：

```tsx
<label className="inline-flex items-start gap-3">
  <Switch checked={enabled} size="md" onCheckedChange={setEnabled} />
  <span>Notifications</span>
</label>
```

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `checked` | `boolean` | 受控开关状态 |
| `defaultChecked` | `boolean` | 非受控默认状态 |
| `size` | `"sm" \| "md" \| "lg"` | 控件尺寸 |
| `disabled` | `boolean` | 是否禁用 |
| `readOnly` | `boolean` | 是否只读 |
| `required` | `boolean` | 表单必填状态 |
| `name` / `value` | `string` | 表单提交字段 |
| `uncheckedValue` | `string` | 未开启时提交的值 |
| `form` | `string` | 关联的 form id |
| `nativeButton` | `boolean` | 是否使用原生 button 行为 |
| `inputRef` | `Ref<HTMLInputElement>` | 访问隐藏 input |
| `checkedIcon` | `ReactNode` | checked 状态下的 thumb 内容 |
| `uncheckedIcon` | `ReactNode` | unchecked 状态下的 thumb 内容 |
| `className` | `string` | 根节点追加 Tailwind class |
| `onCheckedChange` | `(checked: boolean) => void` | 状态变化回调 |
| `...props` | `HTMLMotionProps<"span">` | 传给 thumb motion span 的其余属性 |
