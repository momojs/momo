`Switch` uses Base UI Switch for its hidden input, controlled/uncontrolled state, and form submission semantics. It renders only the switch itself; callers compose labels and descriptions. Customize thumb content with `checkedIcon` / `uncheckedIcon`. The track, thumb content, and focus ring consume momo semantic tokens.

<SwitchPlayground />

## Usage

```tsx
import { Switch } from "@momots/design/components/switch";

<Switch
  checked={enabled}
  size="md"
  aria-label="Notifications"
  onCheckedChange={setEnabled}
/>
```

To add a label, place `Switch` inside an external `label` or alongside one in the layout:

```tsx
<label className="inline-flex items-start gap-3">
  <Switch checked={enabled} size="md" onCheckedChange={setEnabled} />
  <span>Notifications</span>
</label>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `checked` | `boolean` | Controlled switch state |
| `defaultChecked` | `boolean` | Uncontrolled initial state |
| `size` | `"sm" \| "md" \| "lg"` | Control size |
| `disabled` | `boolean` | Whether interaction is disabled |
| `readOnly` | `boolean` | Whether the control is read-only |
| `required` | `boolean` | Whether the form field is required |
| `name` / `value` | `string` | Form submission fields |
| `uncheckedValue` | `string` | Value submitted when off |
| `form` | `string` | Associated form ID |
| `nativeButton` | `boolean` | Whether to use native button behavior |
| `inputRef` | `Ref<HTMLInputElement>` | Access the hidden input |
| `checkedIcon` | `ReactNode` | Thumb content in the checked state |
| `uncheckedIcon` | `ReactNode` | Thumb content in the unchecked state |
| `className` | `string` | Additional Tailwind classes on the root |
| `onCheckedChange` | `(checked: boolean) => void` | State change callback |
| `...props` | `HTMLMotionProps<"span">` | Other props forwarded to the thumb's motion span |
