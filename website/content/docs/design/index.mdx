`@momots/design` 是 momo 的 React 组件层。它把 **Base UI** 的无样式交互能力、**motion** 的过渡动画、以及 **Tailwind CSS** 的样式表达组合起来，用来沉淀项目中可复用、可调试、可 tree-shaking 的组件。

## 安装

```bash
bun add @momots/design @momots/core @momots/host @base-ui/react motion react react-dom remeda type-fest
bun add @hugeicons/react @hugeicons/core-free-icons
```

`@momots/core`、`@momots/host`、`@base-ui/react`、`motion`、`react`、`remeda`、`type-fest` 与 Hugeicons 应作为 peer dependencies 由应用侧提供，避免组件库把 React、基础工具、图标或动画运行时重复打进产物。

Picker 可以手动接入 `@ncdai/wheel-picker`：

```bash
bun add @ncdai/wheel-picker
```

> 当前公开 npm registry 查询不到 `@ncdai/wheel-picker`。如果它来自内部 registry，请在应用侧配置 registry 后安装；组件源码里已经保留 `adapter` 接口用于接入。

## 打包约定

组件库应以 ESM 多入口发布，并把 React、Base UI、motion 和 momo 的基础包保持 external：

```ts
await Bun.build({
  entrypoints,
  format: "esm",
  packages: "external",
  target: "browser",
});
```

同时保留 `sideEffects` 标记与子路径 `exports`，让消费端 bundler 可以安全地移除未使用组件：

```json
{
  "sideEffects": ["**/*.css"],
  "exports": {
    "./components/toggle-group": {
      "types": "./dist/components/toggle-group.d.ts",
      "import": "./dist/components/toggle-group.js"
    },
    "./themes/semantic.css": "./src/themes/semantic.css",
    "./themes/neutral.css": "./src/themes/neutral.css",
    "./themes/anthropic.css": "./src/themes/anthropic.css"
  },
  "files": ["dist", "src/themes"]
}
```

组件 JS 入口不 import 主题文件；主题只通过 `./themes/*` 暴露给应用侧手动引入。

## Tailwind CSS

本网站已经在 `app.css` 中把 Tailwind 扫描范围扩展到 design 源码目录，因此调试 `packages/design/src` 里的 className 时会即时生成样式。发布给外部应用时，建议提供明确的样式入口，或要求消费端通过 `@source` 扫描组件库源码。

## 主题

主题文件不会被组件入口自动引入，应用侧需要在自己的 CSS 中手动 import：

```css
@import "tailwindcss";
@import "@momots/design/themes/neutral.css";
@import "@momots/design/themes/anthropic.css";
```

然后在根元素或局部容器上切换主题类：

```tsx
<div className="theme-anthropic">
  <Button>Action</Button>
</div>

<div className="theme-neutral dark">
  <Button>Action</Button>
</div>
```

组件只消费带 `momo` 前缀的 semantic token，例如 `bg-momo-bg-canvas`、`text-momo-fg-default`、`border-momo-border-default` 与 `ring-momo-ring-focus`。新增主题只需复用同一套命名即可通过替换根元素 class 完成切换。token 的分层结构与每个 token 的具体语义见 [主题与 Token](/docs/design/theme)。
