`Select` 使用 Base UI Select 提供键盘导航、表单提交与无障碍语义，下拉面板与触发器通过 motion 提供进出场与点击反馈。

<SelectPlayground />

## 使用

```tsx
import { Select } from "@momots/design/components/select";

<Select
  value={fruit}
  onChange={setFruit}
  placeholder="Select a fruit..."
  options={[
    { value: "apple", label: "Apple" },
    { value: "banana", label: "Banana" },
    { value: "cherry", label: "Cherry" },
  ]}
/>;
```

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `value` | `T` | 当前选中值 |
| `defaultValue` | `T` | 非受控默认值 |
| `options` | `ControlOption<T>[]` | 选项列表，支持 `label`、`icon`、`disabled`、`className`、`style` |
| `size` | `"sm" \| "md" \| "lg"` | 控件尺寸 |
| `placeholder` | `ReactNode` | 未选中时的占位文案 |
| `disabled` | `boolean` | 是否禁用 |
| `name` | `string` | 表单字段名 |
| `required` | `boolean` | 是否必填 |
| `className` | `string` | 触发器样式（`triggerClassName` 的别名） |
| `triggerClassName` | `string` | 触发器样式 |
| `popupClassName` | `string` | 下拉面板样式 |
| `itemClassName` | `string` | 选项样式 |
| `onChange` | `(value: T) => void` | 选中项变化回调 |
