`ToggleGroup` uses Base UI ToggleGroup for keyboard and selection semantics and motion for its selection indicator. It supports `button`, `segmented`, and `tabbar` variants. Buttons, the indicator, borders, and focus rings all consume momo semantic tokens.

<ToggleGroupPlayground />

## Usage

```tsx
import { ToggleGroup } from "@momots/design/components/toggle-group";

<ToggleGroup
  value={align}
  onChange={(value) => {
    if (value !== undefined) setAlign(value);
  }}
  options={[
    { value: "left", label: "Left", icon: <LeftIcon /> },
    { value: "center", label: "Center", icon: <CenterIcon /> },
    { value: "right", label: "Right", icon: <RightIcon /> },
  ]}
/>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `T` | Current selected value |
| `defaultValue` | `T` | Uncontrolled initial value |
| `options` | `ControlOption<T>[]` | Options supporting `label`, `icon`, `disabled`, `className`, and `style` |
| `size` | `"sm" \| "md" \| "lg"` | Control size |
| `variant` | `"button" \| "segmented" \| "tabbar"` | Appearance variant |
| `onChange` | `(value: T \| undefined) => void` | Selection change callback; `undefined` when all options are deselected |
