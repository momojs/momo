`Checkbox` uses Base UI Checkbox for its hidden input, controlled/uncontrolled state, indeterminate state, and form submission semantics. Its check indicator is drawn with motion; borders, background, text, and focus ring consume momo semantic tokens.

<CheckboxPlayground />

## Usage

```tsx
import { Checkbox } from "@momots/design/components/checkbox";

<Checkbox
  size="md"
  checked={accepted}
  aria-label="Accept terms"
  onCheckedChange={setAccepted}
/>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `checked` | `boolean` | Controlled checked state |
| `defaultChecked` | `boolean` | Uncontrolled initial state |
| `size` | `"sm" \| "md" \| "lg"` | Control size; defaults to `"md"` |
| `indeterminate` | `boolean` | Whether to display a mixed state |
| `disabled` | `boolean` | Whether interaction is disabled |
| `readOnly` | `boolean` | Whether the control is read-only |
| `required` | `boolean` | Whether the form field is required |
| `name` / `value` | `string` | Form submission fields |
| `uncheckedValue` | `string` | Value submitted when unchecked |
| `className` | `string` | Additional Tailwind classes on the root |
| `onCheckedChange` | `(checked: boolean) => void` | State change callback |
