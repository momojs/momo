`useResize` reads initial element dimensions and observes later changes through `ResizeObserver`. It suits chart containers, custom layouts, and scroll regions. Use [useAutoSize](/docs/design/use-auto-size) to register multiple content panels and produce animated dimensions.

## Playground

Adjust container width to observe border-box measurement. Enabling “Scale to 75%” does not change measured dimensions. You can also pause observation, switch layouts, or change the logical key.

Changing `display` remounts the measured node in the demo to show each layout's initial measurement.

| Action | Result |
| --- | --- |
| `display: none` | Reports `0 × 0`, a valid zero size |
| `display: contents` | Reports `null`: the target has no measurable layout box |
| Change width while paused | Retains the last report; reads current dimensions on resume |
| Change logical key | Reports initial dimensions again even if unchanged |

## Reading container dimensions

Store the node in state through a callback ref, then pass it to the hook:

```tsx
import { useState } from "react";
import type { ElementSize } from "@momots/design/hooks";
import { useResize } from "@momots/design/hooks";

function SizeProbe() {
  const [target, setTarget] = useState<HTMLDivElement | null>(null);
  const [size, setSize] = useState<ElementSize | null>(null);

  useResize(target, (_element, next) => setSize(next));

  return (
    <section>
      <div ref={setTarget} className="w-full border p-4">
        Resize the window to observe this container.
      </div>
      <output>
        {size === null
          ? "Not measured or unsupported layout"
          : `${size.width.toFixed(1)} × ${size.height.toFixed(1)} CSS px`}
      </output>
    </section>
  );
}
```

Do not merely pass `ref.current` during rendering and expect automatic subscription. Object-ref assignments do not trigger rerenders; a callback ref with state lets the hook receive initial mounting, replacement, and removal.

## What is measured

The **layout border box** includes content, padding, and borders, excluding margins. `width` and `height` are physical dimensions in CSS pixels and may be fractional; vertical writing modes still return physical axes.

CSS transforms do not change these layout dimensions. For example, `scale(2)` visually enlarges an element without doubling the returned values. The hook does not track position or scroll-only changes.

| Condition | Behavior |
| --- | --- |
| `target === null` | Pauses observation without calling back or clearing existing caller dimensions |
| A valid layout box has zero dimensions | Returns `{ width: 0, height: 0 }` |
| `display: none` | Returns a valid zero size |
| `display: contents` or ordinary non-replaced inline element | Calls back with `null` and warns in development |
| Unsupported layout becomes measurable | Resumes measurement through size observation |

Wrap ordinary inline content with `inline-block`, `block`, `flex`, or `grid` for measurement. The environment must provide `ResizeObserver`; no polyfill is bundled.

## Callbacks and logical binding

The hook subscribes and reads initial dimensions in a layout effect, then notifies only when dimensions or measurement validity change. Updating `onResize` uses the latest committed callback without resubscribing solely because its reference changed.

Virtual lists may reuse one DOM node for different items. Use `key` to represent a new logical binding:

```tsx
useResize(target, (_element, size) => {
  reportItemSize(itemId, size);
}, { key: itemId });
```

Changing `key` resubscribes and reports initial dimensions even if the node and dimensions are unchanged. Notifications from cleaned-up observers are ignored. If callers schedule additional asynchronous work or queued updates, they must still verify that results belong to the current item.

Avoid measurement results continually resizing the measured element, which can cause a feedback loop. Usually measure inner content and update an outer container or another consumer.

## API

```ts
type ElementSize = Readonly<{ width: number; height: number }>;

type ResizeHandler<T extends HTMLElement> = (
  element: T,
  size: ElementSize | null,
) => void;

type ResizeOptions = { key?: unknown };

function useResize<T extends HTMLElement>(
  target: T | null,
  onResize: ResizeHandler<T>,
  options?: ResizeOptions,
): void;
```

The hook returns no dimension state; callers decide how to use callback results. Unmounting, target replacement, or `key` changes disconnect the old observer.
