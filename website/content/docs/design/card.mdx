`Card` 将相关内容组合成一张卡片，沿用 momo 的边框、圆角、文字与间距 token。内容 API 与 Drawer、Popover、Sheet、Dialog 一致：`title`、`description`、`children`、`footer` 提供内容，`slots` 配置节点。

<CardPlayground />

## 基本用法

```tsx
import { Button } from '@momots/design/components/button';
import { Card } from '@momots/design/components/card';

<Card
  title='团队工作区'
  description='集中管理项目与共享资源。'
  footer={<Button size='sm'>查看项目</Button>}
  className='max-w-sm'
>
  <p>当前有 12 个项目和 8 位成员。</p>
</Card>
```

只渲染有内容的区域。省略标题与说明时，不创建 header；省略正文或 footer 时，不创建对应节点，也不保留区域之间的空隙。与其他内容插槽一致，`0` 和空字符串是有效内容，`undefined`、`null`、`false` 表示缺省。

## 外观与间距

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `variant` | `default` | `default` 为主题表面、边框和轻阴影；`outline` 为透明背景与边框；`ghost` 为透明背景且不显示边框 |
| `size` | `md` | `sm` / `md` / `lg` 调整卡片内边距与各区域间距，对应 `momo-space-sm` / `md` / `lg` |
| `className` | — | 根节点样式，用于宽度、布局等定制 |
| `render` | — | 根节点的元素或 `(props, state) => JSX` 回调 |
| `slots` | — | header、标题、说明、正文和页脚的节点配置 |

`size` 不限制卡片宽高。用 `className='max-w-sm'` 等布局类控制宽度，正文默认随内容自然增长，页脚中的操作可以换行。

## 内容插槽

```tsx
<Card
  title='工作区设置'
  description='修改对外展示的信息。'
  footer={<Button>保存</Button>}
  slots={{
    header: <header />,
    title: { render: <h2 />, id: 'workspace-title' },
    description: <p />,
    content: { className: 'grid gap-momo-sm' },
    footer: (props, _state) => <footer {...props} />,
  }}
>
  <SettingsForm />
</Card>
```

每个 slot 支持属性对象、元素简写、render 回调或 `false`；元素和回调也可以放在对象的 `render` 字段中。回调应转发 `props`（包含 ref 和 children），保留样式、事件与内容。

| Slot | 默认节点 | 内容来源 |
| --- | --- | --- |
| `header` | `div` | 标题与说明的容器 |
| `title` | `h3` | `title` |
| `description` | `div` | `description`，支持富文本和块级内容 |
| `content` | `div` | `children` |
| `footer` | `div` | `footer` |

`slots.header=false` 同时移除标题与说明。要改变标题层级，用 `slots.title={{ render: <h2 /> }}`，内容仍放在 `title`。不要将 `children` 放进 slot 配置中。完整约定见 [Content Slots](/docs/design/content-slots)。

## 根节点与语义

根节点默认是普通 `div`。可以通过 `render` 改成 `article`、`section` 或链接，同时保留属性、样式、事件与 ref：

```tsx
<Card
  render={<article aria-labelledby='project-title' />}
  title='项目概览'
  slots={{ title: { id: 'project-title' } }}
>
  项目进度与最近活动。
</Card>

<Card
  render={(props, state) => (
    <section {...props} data-density={state.size} />
  )}
  title='最近活动'
/>
```

根 render 回调收到 `CardState`，包含 `slot: 'card'`、`variant` 和 `size`；这些值也以 `data-slot`、`data-variant`、`data-size` 输出。内容节点的 render state 是空对象。

Card 本身不添加可点击语义、Tab 停靠点或 live region。整张卡片需要导航时使用 `render={<a href='/docs/design' />}`；此时内部应只放非交互内容。带独立按钮或链接的卡片保留普通容器，让操作控件各自负责交互。可访问名称与说明通过原生 ARIA 属性显式设置，Card 不自动创建这些关联。

## 自由组合

需要封面、自定义 header 或不同的内容顺序时，使用独立节点：

```tsx
import {
  CardRoot, CardHeader, CardTitle, CardDescription, CardContent, CardFooter,
} from '@momots/design/components/card';

<CardRoot size='lg' render={<article />}>
  <CardHeader>
    <CardTitle render={<h2 />}>团队工作区</CardTitle>
    <CardDescription>成员与项目一览。</CardDescription>
    <Badge>Pro</Badge>
  </CardHeader>
  <CardContent><ProjectList /></CardContent>
  <CardFooter className='justify-between'>
    <span>8 位成员</span>
    <Button>管理成员</Button>
  </CardFooter>
</CardRoot>
```

所有独立节点都支持原生属性、ref 和 `render`。`CardRoot` 只提供表面与区域间距，直接渲染传入的 children；`Card` 则根据内容属性自动生成这套结构。嵌套卡片各自使用自己的 `size`。
