`usePrevious` 在 Effect 中记录当前值，并在后续渲染时返回这份记录。它适合比较相邻提交前后的页码、日期或选中项。

## 比较当前页与之前的页

```tsx
import { usePrevious } from "@momots/design/hooks";

function PageDirection({ page }: { page: number }) {
  const previous = usePrevious(page);
  const direction = previous === null ? 0 : Math.sign(page - previous);

  return (
    <p>
      当前第 {page} 页；
      {direction > 0 ? "向后翻页" : direction < 0 ? "向前翻页" : "页码未变化"}
    </p>
  );
}
```

## 返回值的时间含义

首次渲染返回 `null`。提交后 Effect 才会保存本次值；保存记录本身不会引发重渲染。

假设每次提交后 Effect 都已执行，行为如下：

| 渲染原因 | 当前 `page` | 返回值 |
| --- | --- | --- |
| 首次挂载 | `1` | `null` |
| 页码改为 2 | `2` | `1` |
| 父组件因其他状态再次渲染 | `2` | `2` |
| 页码改为 3 | `3` | `2` |

它不会持续保存“上一个不同的值”，也不会保存整段历史。如果切换方向需要在整个过渡期间保持不变，应在页码变更时把方向作为独立状态记录，不能依赖这个 Hook 在所有后续渲染中持续返回旧页码。

对象和数组按引用保存，不会创建快照或深拷贝。原地修改对象也会影响已经记录的引用，因此应使用不可变更新。

## API

```ts
function usePrevious<T>(value: T): T | null;
```

服务端渲染不执行 Effect，所以返回 `null`。真实输入值也可能是 `null`，此时无法仅凭返回值区分“尚无记录”和“上次值就是 null”；需要区分时，应由调用方显式建模。
