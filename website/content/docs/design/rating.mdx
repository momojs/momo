`Rating` displays and selects numeric ratings with icons. It supports controlled/uncontrolled state, integer or fractional precision, keyboard operation, read-only display, and native form submission. momo semantic tokens and Motion unify focus, preview, and press feedback.

## Usage

Use `value` and `onValueChange` for controlled ratings:

```tsx
import { Rating } from "@momots/design/components/rating";

const [score, setScore] = useState(3);

<Rating
  aria-label="Experience rating"
  value={score}
  onValueChange={setScore}
/>
```

`Rating` has no visible label. For interaction, provide an accessible name through `aria-label` or `aria-labelledby`.

Use `defaultValue` when the component only needs to manage its initial value:

```tsx
<Rating
  aria-label="Content quality"
  defaultValue={4}
  name="quality"
/>
```

Passing `name` renders a hidden input so the current rating participates in native form submission. Use `form` to associate the control with a form when it sits outside that `form` element.

## Precision and count

`max` sets the maximum rating and defaults to `5`. `precision` sets the smallest selection or keyboard adjustment step and defaults to `1`:

```tsx
<Rating
  aria-label="Product rating"
  defaultValue={3.5}
  max={5}
  precision={0.5}
  variant="yellow"
/>
```

`precision` must be greater than `0`, no greater than `1`, and divide one icon evenly, such as `1`, `0.5`, or `0.25`. Invalid values fall back to `1`. The component clamps the displayed value between `0` and `max` and snaps it to the nearest precision step.

## Pointer interaction

Moving a mouse or stylus within an icon previews a rating according to `precision`; leaving the control restores the selected value. Use `onValueHover` to display the preview value elsewhere. Clicking or tapping confirms the rating. Selecting the current value again clears it to `0`.

Icon fill, hover, and press feedback use motion and respect the user's reduced-motion setting. Increasing the rating fills icons from left to right; decreasing it empties them from right to left. Rapid preview changes continue from the current fill progress. Animation expresses immediate interaction state without changing the rating value or form behavior.

## Read-only and disabled

Use `readOnly` to display an existing rating:

```tsx
<Rating
  aria-label="User rating"
  value={4.5}
  precision={0.5}
  readOnly
/>
```

`readOnly` removes selection interactions while preserving the normal appearance. `disabled` indicates that the control is currently unavailable, removing interactions and reducing visual emphasis. Do not use `disabled` for a read-only display.

## Icons and styling

The default icon is a star. `icon` accepts a Hugeicons icon definition, letting you replace the appearance without changing the rating behavior:

```tsx
import { FavouriteIcon } from "@hugeicons/core-free-icons";
import { Rating } from "@momots/design/components/rating";

<Rating
  aria-label="Preference rating"
  icon={FavouriteIcon}
  variant="destructive"
/>
```

Use `itemClassName` to adjust each rating item's layout or interaction area. Use `emptyIconClassName` and `filledIconClassName` to extend the empty and filled icon styles. Prefer the built-in `variant` in application code, overriding style slots only when a theme extension requires it.

## Keyboard and accessibility

When focused, the control supports these operations:

- `ArrowRight` / `ArrowUp`: increase the rating by `precision`, stopping at `max`.
- `ArrowLeft` / `ArrowDown`: decrease the rating by `precision`, stopping at `0`.
- `Home` / `End`: jump to `0` or the maximum rating.
- `Space` / `Enter`: select the first step when the value is `0`; otherwise clear it to `0`.

`getValueLabel` generates a localized description for assistive technology:

```tsx
<Rating
  aria-label="Service rating"
  value={score}
  getValueLabel={(value, max) => `${value} out of ${max}`}
/>
```

Do not communicate the rating through icon color alone. Add a numeric text value near the control when displaying the result.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `number` | Controlled rating value |
| `defaultValue` | `number` | Uncontrolled initial value; defaults to `0` |
| `max` | `number` | Maximum rating; defaults to `5` |
| `precision` | `number` | Selection and keyboard adjustment step; defaults to `1` |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | Icon size; defaults to `"sm"` |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "yellow"` | Icon appearance; defaults to `"default"` |
| `icon` | Hugeicons icon definition | Custom rating icon |
| `name` / `form` | `string` | Form field name and associated form |
| `readOnly` | `boolean` | Read-only display without selection interactions |
| `disabled` | `boolean` | Disable the control |
| `getValueLabel` | `(value: number, max: number) => string` | Generate an accessible description of the current value |
| `onValueChange` | `(value: number) => void` | Rating change callback |
| `onValueHover` | `(value: number) => void` | Pointer preview change callback; returns `0` on exit |
| `className` | `string` | Additional Tailwind classes for the root element |
| `itemClassName` | `string` | Additional Tailwind classes for each rating item |
| `emptyIconClassName` | `string` | Additional Tailwind classes for empty icons |
| `filledIconClassName` | `string` | Additional Tailwind classes for filled icons |
| `...props` | `React.ComponentProps<"div">` | Other native div attributes |
