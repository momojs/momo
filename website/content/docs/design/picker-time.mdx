`PickerTime` uses `PickerCore` to generate hour/minute/meridiem columns. Its panel, selected row, text, and focus ring use momo semantic tokens.

<PickerTimePlayground />

## Usage

```tsx
import { PickerTime } from "@momots/design/components/picker-time";

<PickerTime value={time} onChange={setTime} />
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `Date` | Controlled time |
| `defaultValue` | `Date` | Uncontrolled initial time; defaults to the current time when the module initializes |
| `disabled` | `boolean` | Whether interaction is disabled |
| `onChange` | `(value: Date) => void` | Time change callback; preserves the current date and resets seconds and milliseconds to zero |
