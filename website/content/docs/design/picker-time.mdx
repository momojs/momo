`PickerTime` 基于 `PickerCore` 生成 hour/minute/meridiem 三列，面板、选中行、文本与 focus ring 使用 momo semantic token。

<PickerTimePlayground />

## 使用

```tsx
import { PickerTime } from "@momots/design/components/picker-time";

<PickerTime value={time} onChange={setTime} />
```

## Props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `value` | `string` | `hh:mm a` 格式，例如 `09:30 AM` |
| `defaultDate` | `string` | 非受控默认时间 |
| `disabled` | `boolean` | 是否禁用 |
| `onChange` | `(value: string) => void` | 时间变化回调 |
