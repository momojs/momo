`Slider` supports controlled/uncontrolled numeric selection, dragging, click positioning, and keyboard adjustment. Motion animates fill and thumb, with tick marks for coarse steps (at most 10 intervals).

<SliderPlayground />

## Usage

```tsx
import { Slider } from "@momots/design/components/slider";

<Slider
  label="Opacity"
  value={opacity}
  onValueChange={setOpacity}
  min={0}
  max={1}
  step={0.01}
/>
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `label` | `string` | Label on the left inside the track |
| `value` | `number` | Controlled value |
| `defaultValue` | `number` | Uncontrolled initial value; defaults to `min` |
| `onValueChange` | `(value: number) => void` | Value-change callback |
| `min` | `number` | Minimum; defaults to `0` |
| `max` | `number` | Maximum; defaults to `1` |
| `step` | `number` | Minimum increment; defaults to `0.01` |
| `formatValue` | `(value: number) => string` | Custom right-side display formatting |
| `className` | `string` | Additional Tailwind classes on the container |
| `aria-label` | `string` | Accessible name; defaults to `label` |

## Interaction details

- **Dragging**: exceeding bounds produces a rubber-band return, respecting `prefers-reduced-motion`.
- **Value display**: `TweenNumber` follows dragging immediately and smoothly transitions click, keyboard, and external updates, preserving step precision and `formatValue`. Reduced motion updates immediately.
- **Clicking**: with at most 10 steps, snaps to the nearest step; continuous sliders snap to the nearest 10% tick.
- **Keyboard**: `ArrowLeft`/`ArrowRight` adjust by `step`; `Shift` + arrows by `10 × step`; `Home`/`End` jump to minimum/maximum.
