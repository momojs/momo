`Badge` wraps Base UI's `useRender` and renders a `span` by default. It provides semantic variants, consistent sizes, and momo semantic tokens, and can be composed as a link through `render`.

<BadgePlayground />

## Usage

```tsx
import { Badge } from "@momots/design/components/badge";

<Badge variant="success">Synced</Badge>
```

Pass icons directly as children. Hide decorative icons from the accessibility tree:

```tsx
import { Clock01Icon } from "@hugeicons/core-free-icons";
import { HugeiconsIcon } from "@hugeicons/react";

import { Badge } from "@momots/design/components/badge";

<Badge variant="warning" size="md">
  <HugeiconsIcon icon={Clock01Icon} aria-hidden />
  Processing
</Badge>
```

## Status semantics

Choose a variant to express the content's meaning, rather than only matching a page color:

| Variant | Meaning |
| --- | --- |
| `default` | Neutral information or general metadata |
| `brand` | Brand labels, current categories, or highlighted information |
| `success` | Completed, available, or operating normally |
| `warning` | Pending, requiring attention, or potentially risky |
| `danger` | Failed, unavailable, or high-risk status |
| `outline` | Low-emphasis categories and supporting metadata |

Use clear status text such as “Synced” or “Awaiting review”; do not rely on color alone.

## Polymorphic links

With `render`, Badge merges its classes, data attributes, and native attributes onto the target element. A link should still use a real `a` element:

```tsx
<Badge
  variant="brand"
  render={<a href="/docs/design" />}
>
  View component docs
</Badge>
```

The default Badge is a presentational label without button interaction semantics. Use `Button` to perform actions; compose Badge as a link only when its content navigates elsewhere.

## Accessibility

- Badge does not automatically add `role="status"` or `aria-live`, so static labels are not repeatedly announced by assistive technology.
- For dynamic status updates requiring immediate notification, decide at the application level whether to use an outer live region.
- Add `aria-hidden` to decorative icons; icons with independent meaning need accessible names.
- Express status with clear text as well as color so users with different visual abilities can understand it.
- When composing a link, use text that conveys its purpose out of context and preserve visible keyboard focus.

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `variant` | `"default" \| "brand" \| "success" \| "warning" \| "danger" \| "outline"` | Status semantics and appearance; defaults to `"default"` |
| `size` | `"sm" \| "md" \| "lg"` | Label size; defaults to `"md"` |
| `children` | `ReactNode` | Label content, including SVG icons |
| `render` | `ReactElement \| ((props, state) => ReactElement)` | Compose the default `span` as another element, such as a link |
| `className` | `string` | Additional Tailwind classes |
| `...props` | `useRender.ComponentProps<"span">` | Other native attributes and Base UI render props |
