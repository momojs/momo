title: Substitute

`substitute` splits template text into an array of strings and React nodes, useful for inserting links, emphasis, or other inline content into messages.

## Imports

```tsx
import { substitute } from "@momots/design/shared";
```

This version preserves React nodes. For plain strings, use [`@momots/core/substitute`](/docs/core/guide#substitute).

## Interpolating text and nodes

```tsx
function Agreement() {
  return (
    <p>
      {substitute("Continuing means you agree to the {{terms}}. Your trial lasts {{days}} days.", {
        terms: <a key="terms" href="https://example.com/terms">Terms of Service</a>,
        days: 14,
      })}
    </p>
  );
}
```

Inserted nodes retain their props. Strings, numbers, and symbols become strings; other values retain their identity before null filtering. Give React elements stable `key` values as array children. For repeated elements, use different placeholder names and keys per position.

## Default values

Placeholders support `{{key}}` and `{{key|default text}}`. Keys consist of English letters, digits, or underscores; whitespace is not trimmed and path access is unsupported.

```tsx
substitute("Name {{name|Unknown}}", {});
// ["Name ", "Unknown"]

substitute("Name {{name}}", {});
// ["Name ", "name"]

substitute("Count {{count|None}}", { count: 0 });
// ["Count ", "0"]

substitute("Before{{name|}}after", {});
// ["Before", "after"]
```

Only the interpolation object's own properties are read. Missing fields, `null`, or `undefined` use default text, or the key if no default exists. `false`, empty strings, and empty arrays do not trigger defaults but are removed during empty-value filtering. `0` and `bigint` retain renderable values.

Everything after the first `|` is default text, including subsequent `|` characters. Nested expressions containing braces are unsupported. Interpolated results are not parsed again as templates.

## API and boundaries

```ts
function substitute<T = PropertyKey | React.ReactNode>(
  data?: string,
  interpolation?: Record<string, T>,
): (T | string)[];
```

- An empty template returns an empty array.
- Ordinary braces, unrecognized placeholders, and unclosed text remain unchanged; for example, `{name}` and `{{bad key}}` are not interpolated.
- The function does not parse HTML strings; strings still render as React text.
- Generics preserve custom values, but callers must ensure they are renderable when passing results directly to React.
- The returned array is filtered with `compact`. Beyond empty strings, `false`, and empty arrays, values such as empty objects may also be removed. See [`compact`](/docs/core/guide#compact).
